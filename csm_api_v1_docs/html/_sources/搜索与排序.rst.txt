搜索与排序
===============

系统提供的列表类接口，一般均支持搜索与排序，此章节介绍使用方法，具体支持的参数请参考接口中描述。

搜索
------------
| 系统目前支持是搜索类型有 ``精确`` ``模糊`` ``范围`` ``精确多选``
| 每个字段只支持一种类型的搜索，请参照接口中说明

* 调用方式

| 将参数在uri中传递，例如

.. code-block:: bash

    /api/v1/ip?ip=1.1.1.1

精确
^^^^^^^^^^^^^^^^^^^^^^^^
| 直接将需要搜索的值通过参数传递，例如

.. code-block:: bash

    /api/v1/ip?id=1

模糊
^^^^^^^^^^^^^^^^^^^^^^^^

| 直接将需要搜索的值通过参数传递，例如

.. code-block:: bash

    /api/v1/ip?ip=1.1.1.1

范围
^^^^^^^^^^^^^^^^^^^^^^^^

| 一般是时间范围
| 将起始值与结束值使用 ``/`` 连接，支持三种时间格式，例如

.. code-block:: bash

    /api/v1/ip?uptime=2020-7-20/2020-8-20

或者

.. code-block:: bash

    /api/v1/ip?uptime=2020-7-20T14:12:00/2020-8-20T16:22:00

或者

.. code-block:: bash

    /api/v1/ip?uptime=2020-7-20 14:12:00/2020-8-20 16:22:00

使用空格时，请注意编码问题

精确多选
^^^^^^^^^^^^^^^^^^^^^^^^

| 多个值使用英文逗号 ``,`` 分隔，例如

.. code-block:: bash

    /api/v1/ip?taskids=123,124,125

.. note:: 多个字段同时查询时，处理逻辑为 ``and``

排序
----------
| 系统支持对列表返回内容进行排序，每个接口支持排序字段不同，请参考接口中说明
| 通过ordering参数在uri中传递，例如

.. code-block:: bash

    /api/v1/ip?ordering=id,ip

支持多个字段同时排序，以英文逗号 ``,`` 分隔，上述例子表示安照 ``id正序``、``ip正序`` 的顺序进行排序

* 正序与倒序

| 默认为正序排序，当需要倒序时，可在参数前加上 ``-`` 表示倒序
| 例如按照 ``id正序``、``ip倒序`` 的顺序进行排序的写法为

.. code-block:: bash

    /api/v1/ip?ordering=id,-ip

.. note:: 不指定排序时，默认排序为id倒序
