版本型漏洞批量复扫
==============================

用于进行版本型漏洞的复扫操作

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

  PUT /api/v1/version/verify

请求参数
+++++++++++++++++++++

+-----------+------------+----------+------------------------------+-----------------------+
| 字段      | 字段名称   | 是否必填 | 说明                         | 示例                  |
+===========+============+==========+==============================+=======================+
| zone_name | 区域标识   | 否       | 不传值时将自动分配区域       | 例如：default         |
+-----------+------------+----------+------------------------------+-----------------------+
| id        | 漏洞id数组 | 否       | 整数数组                     | 例如 [1,2,3,4]        |
+-----------+------------+----------+------------------------------+-----------------------+
| {id}      | 漏洞ID     | 否       | 漏洞id作为键，区域标识作为值 | 例如 {"1": "default"} |
+-----------+------------+----------+------------------------------+-----------------------+

详细说明
+++++++++++++++++
* 传参方式有两种
  
1. 区域标识通过zone_name传递，漏洞id通过id字段传递，例如

.. code-block:: json

   {  
        "zone_name":"default", 
        "id": [1,3,4,29301,29236]
    }

2. 漏洞id、区域标识进行一一指定，例如
   
.. code-block:: json

    {
        "1": "default",
        "2": "test",
        "29301": null,
        "29236": null
    }

.. note:: 以上两种形式，zone_name均可不指定，系统将尝试根据任务记录自动获取，获取失败时，返回错误信息，所有复扫不下发

请求示例
+++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:8000/api/v1/version/verify"

    payload = json.dumps({
        "1": "default",
        "2": "test",
        "29301": null,
        "29236": null
    })

    headers = {
        'Accept': 'application/json',
        'Content-type': 'application/json',
        'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
        'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
    }

    response = requests.request("PUT", url, headers=headers, data=payload)

    print(response.text)


Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict              返回信息
=============   ===============   ===============


示例值
+++++++++

.. code-block:: javascript

    {
        "info": {
            "msg": "下发成功",
            "error": [
                {
                    "id": "29301",
                    "name": "配置文件泄漏",
                    "msg": "区域连接失败, 请检查配置是否正确"
                }
            ]
        },
        "status": true
    }

失败示例
+++++++++

.. code-block:: javascript

    {
        "info": [
            "id=29236的漏洞扫描区域未能自动获取, 请手动指定"
        ],
        "status": false
    }

.. note:: 通过返回信息中的status判断是否成功下发任务，当成功下发时，仍可能有部分漏洞下发失败，原因记录在info-error中
