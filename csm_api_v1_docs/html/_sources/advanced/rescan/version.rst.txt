版本型漏洞复扫
================

用于进行版本型漏洞的复扫操作

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

  PUT /api/v1/version/verify/{id}

请求参数
+++++++++++++++++++++

+-----------+----------+----------+------------------------+---------------+
| 字段      | 字段名称 | 是否必填 | 说明                   | 示例          |
+===========+==========+==========+========================+===============+
| zone_name | 区域标识 | 否       | 不传值时将自动分配区域 | 例如：default |
+-----------+----------+----------+------------------------+---------------+


请求示例
+++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:8000/api/v1/version/verify/29192"

    payload = json.dumps({
        "zone_name": "default"
    })

    headers = {
        'Accept': 'application/json',
        'Content-type': 'application/json',
        'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
        'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
    }

    response = requests.request("PUT", url, headers=headers, data=payload)

    print(response.text)


Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict/string       返回信息
=============   ===============   ===============


示例值
+++++++++

.. code-block:: javascript

    {
        "info": "操作成功",
        "status": true
    }


失败示例
+++++++++

.. code-block:: javascript

    {
        "info": {
            "detail": "Not found."
        },
        "status": false
    }
