导出记录列表
===========================================

用于获取导出报告-导出记录列表

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/report/map


搜索参数
+++++++++++++++++++++

+------------+--------------+----------+----------------------------------+
| 字段       | 字段名称     | 查询方式 | 说明                             |
+============+==============+==========+==================================+
| id         | ID           | 精确     |                                  |
+------------+--------------+----------+----------------------------------+
| name       | 导出任务名称 | 模糊     |                                  |
+------------+--------------+----------+----------------------------------+
| status     | 模板状态     | 精确     | 0:导出失败 1:正在导出 2:导出完成 |
+------------+--------------+----------+----------------------------------+
| cycle      | 是否周期任务 | 精确     | 0:否 1:是                        |
+------------+--------------+----------+----------------------------------+
| type       | 导出报告格式 | 精确     | html、docx、wps                  |
+------------+--------------+----------+----------------------------------+
| group_ids  | 关联资产组ID | 精确     |                                  |
+------------+--------------+----------+----------------------------------+
| task_ids   | 关联任务ID   | 精确     |                                  |
+------------+--------------+----------+----------------------------------+
| createtime | 创建时间     | 范围     | 例如：2020-7-20/2020-8-20        |
+------------+--------------+----------+----------------------------------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/report/map?attach=count&id=1&name=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **createtime** ✅：创建时间
- **name** ✅：导出任务名称
- **cycle** ✅：是否周期任务 ``1：是`` ``0：否``
- **task_ids**：关联任务id
- **group_ids**：关联资产组id
- **type** ✅：报告类型docx/wps/html
- **status** ✅：任务状态 ``1: 正在导出`` ``2: 导出完成`` ``0: 导出失败``
- **user_id**: 模板创建用户id

.. note:: ✅ 表示该字段可排序
