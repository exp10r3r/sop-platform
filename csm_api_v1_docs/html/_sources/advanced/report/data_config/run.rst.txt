立即生成
==============================================================

用于立即按照模板导出数据，导出将于后台执行，结果在「导出数据-导出记录」中查询

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/report/data/config/run/{id}



请求参数
+++++++++++++++++++++

无

请求示例
+++++++++
   
.. code-block:: python

    import requests

    url = "http://127.0.0.1:38202/api/v1/report/data/config/run/771"

    payload={}
    headers = {}

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)



Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict              返回数据
=============   ===============   ===============


示例值
+++++++++

.. code-block:: javascript

    {
        "info": {
            "id": 1469,
            "createtime": "2023-03-21 14:22:10",
            "name": "tast-api-report-data",
            "cycle": 0,
            "task_name": "",
            "group_name": "",
            "task_ids": [],
            "group_ids": [],
            "uuid": "b6767a64-c7b0-11ed-9ae7-acde48001122",
            "type": "xlsx",
            "status": 1,
            "user_id": 1,
            "generate_type": "template"
        },
        "status": true
    }

- **id**：导出记录的id


  
失败示例
+++++++++

.. code-block:: javascript

    {
        "info": {
            "detail": "Not found."
        },
        "status": false
    }
