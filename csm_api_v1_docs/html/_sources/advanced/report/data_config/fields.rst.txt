自定义导出字段详情
=============================================================

当用户需要自定义某个报表的输出字段时，可以查询此接口


Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/report/data/config/fields


请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/report/data/config/fields
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict              返回数据
=============   ===============   ===============

数据字段详解：

info是一个dict对象
info的键是导出的报表标识（对应的模板配置中condition内容，如task代表扫描任务、ip代表IP资产）
info的值 也是一个dict对象，键代表字段名称，值代表导出的Excel报表中数据列的中文列名

.. note:: ✅ 表示该字段可排序
