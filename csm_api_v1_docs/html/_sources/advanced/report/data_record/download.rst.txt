下载导出文件
===========================================

用于下载导出报告的文件

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/report/data/{id}


请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/report/data/711
