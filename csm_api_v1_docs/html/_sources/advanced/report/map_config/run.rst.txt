立即生成
==============================================================

用于立即按照模板导出报告，导出将于后台执行，结果在「导出报告-导出记录」中查询

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/report/map/config/run/{id}



请求参数
+++++++++++++++++++++

无

请求示例
+++++++++
   
.. code-block:: python

    import requests

    url = "http://127.0.0.1:38202/api/v1/report/map/config/run/771"

    payload={}
    headers = {}

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)



Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict              返回数据
=============   ===============   ===============
