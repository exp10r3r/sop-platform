扫描区域列表
================

用于获取扫描区域信息

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/zones



搜索参数
+++++++++++++++++++++

+---------+----------+----------+------+
| 字段    | 字段名称 | 查询方式 | 说明 |
+=========+==========+==========+======+
| id      | 区域id   | 精确     |      |
+---------+----------+----------+------+
| name    | 区域名称 | 模糊     |      |
+---------+----------+----------+------+
| value   | 区域标识 | 模糊     |      |
+---------+----------+----------+------+
| content | 区域描述 | 模糊     |      |
+---------+----------+----------+------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/zones?attach=count&id=1&name=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **name** ✅：区域名称
- **value** ✅：区域标识
- **content** ✅：区域描述
- **max_concurrency**：最大并发数
- **node_count**：区域节点数
- **activity_node_count**：区域存活节点数


.. note:: ✅ 表示该字段可排序
