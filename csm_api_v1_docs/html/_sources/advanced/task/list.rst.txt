任务列表
================

用于获取任务列表

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/task



搜索参数
+++++++++++++++++++++

+-------------+--------------+----------+----------------------------------+
| 字段        | 字段名称     | 查询方式 | 说明                             |
+=============+==============+==========+==================================+
| id          | 任务id       | 精确     |                                  |
+-------------+--------------+----------+----------------------------------+
| name        | 任务名称     | 模糊     |                                  |
+-------------+--------------+----------+----------------------------------+
| scan_type   | 扫描方式     | 精确     |                                  |
+-------------+--------------+----------+----------------------------------+
| cycle       | 扫描频率     | 精确     | 0:单次扫描 1:周期执行 2:计划执行 |
+-------------+--------------+----------+----------------------------------+
| task_type   | 任务类型     | 精确     |                                  |
+-------------+--------------+----------+----------------------------------+
| value_type  | 目标范围     | 精确     |                                  |
+-------------+--------------+----------+----------------------------------+
| portdeep    | 端口发现方式 | 精确     |                                  |
+-------------+--------------+----------+----------------------------------+
| zone_name   | 性能区域标识 | 模糊     |                                  |
+-------------+--------------+----------+----------------------------------+
| start_time  | 开始时间     | 范围     | 例如：2020-7-20/2020-8-20        |
+-------------+--------------+----------+----------------------------------+
| end_time    | 结束时间     | 范围     | 例如：2020-7-20/2020-8-20        |
+-------------+--------------+----------+----------------------------------+
| create_time | 创建时间     | 范围     | 例如：2020-7-20/2020-8-20        |
+-------------+--------------+----------+----------------------------------+
| status      | 任务状态     | 精确多选 |                                  |
+-------------+--------------+----------+----------------------------------+
| user_id     | 用户ID       | 精确多选 | 例如:1,2,3,4                     |
+-------------+--------------+----------+----------------------------------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/task?attach=count&id=1&name=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **name** ✅：任务名称
- **scan_type** ✅：扫描方式 ``base：基础模式`` ``domain：主域模式`` ``pocscan：PoC巡检`` ``thirdscan：第三方扫描`` 
- **task_type** ✅：扫描方式 ``senior：高级自定义`` ``assets：资产探测`` ``version：版本型漏洞扫描`` ``poc：PoC漏洞扫描`` ``pocscan：PoC巡检```
- **value_type** ✅：目标范围 ``customize：自定义`` ``exist_ip：资产库所有IP和域名`` ``business：资产组``
- **value**：目标信息
- **cycle** ✅：扫描频率 ``0:单次扫描`` ``1:周期执行`` ``2:计划执行`` 
- **portdeep** ✅：端口发现方式 ``1：急速模式`` ``2：标准模式``
- **status** ✅：任务状态 **基础模式**: ``0: 未开始`` ``-1：暂停`` ``1: 端口服务探测`` ``3: os识别`` ``5: 插件扫描`` ``6: 完成`` ``7: 任务终止``  **主域模式**: ``0: 未开始`` ``-1：暂停`` ``10: 子域名收集`` ``11: 端口探测`` ``12: 数据分析`` ``13: 初步端口探测`` ``15: 站点指纹识别`` ``3: os识别`` ``5: os识别完成`` ``6: 完成`` ``7: 任务终止``
- **zone_name** ✅：扫描区域
- **start_time** ✅：开始时间
- **end_time** ✅：结束时间
- **create_time** ✅：创建时间
- **user_id**: 用户id

.. note:: ✅ 表示该字段可排序
