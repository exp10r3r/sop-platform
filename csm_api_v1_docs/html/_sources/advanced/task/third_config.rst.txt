扫描器配置字段详情
=============================================================

用户下发第三方扫描任务时，需要提交taskcfg参数，使用此接口，可查询taskcfg需要提交的参数详情

此接口包含了扫描器列表与每个扫描器的配置参数想去

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/task_manage/third_config


请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/task_manage/third_config
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict              返回数据
=============   ===============   ===============

数据字段详解: 

- **name**: 扫描器类型显示名称
- **type**: 扫描器类型标识
- **collector**: 扫描器列表，数组格式
  
  - **id**: 扫描器ID
  - **name**: 扫描器名称
  - **collector_type**: 扫描器类型
  - **config**: 配置详情，数组格式

    - **id**: 配置id
    - **type**: 配置类型 ``select: 选择框`` ``password: 密码输入框`` ``input: 输入框`` ``checkbox: 选择框`` ``switch: 开关`` ``textarea: 文本域`` 
    - **title**: 字段显示名称
    - **name**: 字段传值名称
    - **default_value**: 默认值
    - **values**: 可选值
    - **placeholder**: 简要提示信息
    - **detailed**: 详细提示信息
    - **is_must**: 是否必填 ``1: 是`` ``0: 否``
    - **error_info**: 错误提示信息
    - **multiple**: 是否多选 ``1: 是`` ``0: 否``
