版本型漏洞批量流转与处置
=========================

用于进行版本型漏洞的批量处置、流转

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

  POST /api/v1/version/status

请求参数
+++++++++++++++++++++

+------------+----------+----------+------------------------------+------+
| 字段       | 字段名称 | 是否必填 | 说明                         | 示例 |
+============+==========+==========+==============================+======+
| id         | ID       | 是       | 需求处置的漏洞id，格式为数组 |      |
+------------+----------+----------+------------------------------+------+
|| status    || 状态    || 否      || 0: 未处理                   ||     |
||           ||         ||         || 1: 已确认                   ||     |
||           ||         ||         || 2: 已修复                   ||     |
||           ||         ||         || 3: 误报                     ||     |
||           ||         ||         || 4: 待修复                   ||     |
||           ||         ||         || 5: 修复失败                 ||     |
||           ||         ||         || 6: 已验证                   ||     |
||           ||         ||         || 7: 忽略                     ||     |
+------------+----------+----------+------------------------------+------+
| handler_id | 处理人id | 否       |                              |      |
+------------+----------+----------+------------------------------+------+


请求示例
+++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:8000/api/v1/version/status"

    payload = json.dumps({
        "handler_id": "98",
        "status": 4,
        "id": [1,3,4,29301, 226328]
    })

    headers = {
        'Accept': 'application/json',
        'Content-type': 'application/json',
        'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
        'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
    }

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)


Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict/string       返回信息
=============   ===============   ===============


示例值
+++++++++

.. code-block:: javascript

    {
        "info": "操作成功",
        "status": true
    }


失败示例
+++++++++

.. code-block:: javascript

    {
        "info": {
            "id": "未找到任何匹配项."
        },
        "status": false
    }
