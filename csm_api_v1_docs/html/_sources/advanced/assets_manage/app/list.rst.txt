应用组列表
================

用于获取应用组列表

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/group/app



搜索参数
+++++++++++++++++++++

+---------+--------------+----------+------+
| 字段    | 字段名称     | 查询方式 | 说明 |
+=========+==============+==========+======+
| id      | 任务id       | 精确     |      |
+---------+--------------+----------+------+
| name    | 应用组名称   | 模糊     |      |
+---------+--------------+----------+------+
| user_id | 负责人id     | 精确多选 |      |
+---------+--------------+----------+------+
| remarks | 备注         | 精确     |      |
+---------+--------------+----------+------+
| pid     | 父级资产组id | 精确     |      |
+---------+--------------+----------+------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/group/app?attach=count&id=1&name=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **name** ✅：应用组名称
- **user_id**：负责人id
- **assets_count**：关联资产IP数
- **poc_count**：关联PoC漏洞
- **version_count**：关联版本型漏洞
- **remarks**：备注  
- **pid**：父级应用组id

.. note:: ✅ 表示该字段可排序
