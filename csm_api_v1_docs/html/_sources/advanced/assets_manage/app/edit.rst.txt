编辑应用组
================

用于编辑应用组

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   PUT /api/v1/group/app/{id}



请求参数
+++++++++++++++++++++

+---------+--------------+----------+-----------------------------+------+
| 字段    | 字段名称     | 是否必填 | 说明                        | 示例 |
+=========+==============+==========+=============================+======+
| name    | 任务名称     | 是       |                             |      |
+---------+--------------+----------+-----------------------------+------+
| pid     | 父级应用组id | 是       | 不指定父级应用组时请传值 -1 |      |
+---------+--------------+----------+-----------------------------+------+
| user_id | 负责人id     | 否       |                             |      |
+---------+--------------+----------+-----------------------------+------+
| remarks | 备注         | 否       |                             |      |
+---------+--------------+----------+-----------------------------+------+

请求示例
+++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:38202/api/v1/group/app/7388"

    payload = json.dumps({
        "name": "test",
        "pid": -1,
        "user_id": [
            1,
            2,
            3
        ],
        "remarks": "测试"
    })
    headers = {
        'ACCESSKEY': 'B6xsfMw2SztH3YTv5bWLHynfciajICMgNWomlFOhn14xcssRQQk0Q',
        'SECRETKEY': 'FhfAkrtBNnjRHQdnF0H0JiDeHykb0tQb0JlLSFu9v92Tp31i3M22EaIMSVIKqi8lk',
        'Content-Type': 'application/json',
        'Cookie': 'sessionid=4dw4q32m1i9b98mmb7ymuynm0ol8jjfs'
    }

    response = requests.request("PUT", url, headers=headers, data=payload)

    print(response.text)



Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict              返回数据
=============   ===============   ===============


示例值
+++++++++

.. code-block:: javascript

    {
        "info": {
            "id": 7389,
            "name": "test2",
            "user_id": [
                1

            "assets_count": 0,
