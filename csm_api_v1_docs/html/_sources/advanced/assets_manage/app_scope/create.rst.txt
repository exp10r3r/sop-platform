创建应用组范围登记
===========================================

用于创建应用组范围登记

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/group/app/scope



请求参数
+++++++++++++++++++++

+---------------+--------------+----------+----------------------------+--------------+
| 字段          | 字段名称     | 是否必填 | 说明                       | 示例         |
+===============+==============+==========+============================+==============+
| value         | 资产范围     | 是       |                            |              |
+---------------+--------------+----------+----------------------------+--------------+
|| ports        || 端口范围    || 否      || scope_tpye为0/1/2时必填   || 80,443,8080 |
||              ||             ||         || 可选值为all（表示全端口） ||             |
||              ||             ||         || 或者使用逗号分隔的端口号  ||             |
+---------------+--------------+----------+----------------------------+--------------+
| priority      | 优先级       | 是       | 1-100                      |              |
+---------------+--------------+----------+----------------------------+--------------+
|| scope_type   || 范围类型    || 是      || 0:IP/域名                 ||             |
||              ||             ||         || 1:资产来源                ||             |
||              ||             ||         || 2:关联任务                ||             |
||              ||             ||         || 3:端口服务                ||             |
+---------------+--------------+----------+----------------------------+--------------+
| groupids      | 应用组id     | 否       |                            |              |
+---------------+--------------+----------+----------------------------+--------------+
| remarks       | 备注         | 否       |                            |              |
+---------------+--------------+----------+----------------------------+--------------+
| level         | 资产等级     | 否       |                            |              |
+---------------+--------------+----------+----------------------------+--------------+
| system_source | 系统来源     | 否       |                            |              |
+---------------+--------------+----------+----------------------------+--------------+
| supplier      | 供应商       | 否       |                            |              |
+---------------+--------------+----------+----------------------------+--------------+
| contract      | 安全合同约束 | 否       |                            |              |
+---------------+--------------+----------+----------------------------+--------------+

请求示例
+++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:38202/api/v1/group/app/scope"

    payload = json.dumps({
        "value": "matrix11.xxxxxxx.com",
        "ports": "all",
        "priority": 11,
        "groupids": [
            7389
        ],
        "scope_type": 2,
        "remarks": "这是备注",
        "level": null,
        "system_source": "",
        "supplier": "",
        "contract": ""
    })
    headers = {
        'ACCESSKEY': 'B6xsfMw2SztH3YTv5bWLHynfciajICMgNWomlFOhn14xcssRQQk0Q',
        'SECRETKEY': 'FhfAkrtBNnjRHQdnF0H0JiDeHykb0tQb0JlLSFu9v92Tp31i3M22EaIMSVIKqi8lk',
        'Content-Type': 'application/json',
        'Cookie': 'sessionid=4dw4q32m1i9b98mmb7ymuynm0ol8jjfs'
    }

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)

~~~~~~~~

++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功

=============   ===============   ===============
