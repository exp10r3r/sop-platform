网络组范围登记列表
================================

用于获取网络组范围登记列表

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/group/net/scope



搜索参数
+++++++++++++++++++++

+------------------+--------------+----------+------+
| 字段             | 字段名称     | 查询方式 | 说明 |
+==================+==============+==========+======+
| id               | 任务id       | 精确     |      |
+------------------+--------------+----------+------+
| value            | 资产范围     | 模糊     |      |
+------------------+--------------+----------+------+
| scope_type       | 范围类型     | 精确     |      |
+------------------+--------------+----------+------+
| remarks          | 备注         | 模糊     |      |
+------------------+--------------+----------+------+
| groupids         | 父级资产组id | 精确     |      |
+------------------+--------------+----------+------+
| address          | 地址         | 模糊     |      |
+------------------+--------------+----------+------+
| computer_room    | 机房         | 模糊     |      |
+------------------+--------------+----------+------+
| isp              | 运营商       | 模糊     |      |
+------------------+--------------+----------+------+
| bandwidth        | 带宽         | 模糊     |      |
+------------------+--------------+----------+------+
| cabinet          | 机柜         | 模糊     |      |
+------------------+--------------+----------+------+
| equipment_number | 设备编号     | 模糊     |      |
+------------------+--------------+----------+------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/group/net/scope?attach=count&id=1&value=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **value** ✅：资产范围
- **scope_type** ✅：范围类型  ``0:IP/域名`` ``1:资产来源`` ``2:关联任务``
- **priority** ✅：优先级，1-100，数字越大优先级越高
- **assets_group**：网络组信息
    - **id**：网络组id 
    - **name**：网络组名称
- **remarks** ✅：备注  
- **address**：地址
- **computer_room**：机房
- **isp**：运营商
- **bandwidth**：带宽
- **cabinet**：机柜
- **equipment_number**：设备编号

.. note:: ✅ 表示该字段可排序
