结果列表
=======================

用于获取影子资产监测数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/shadow

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/shadow?attach=count&id=1&name=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解:

- **id** ✅:在数据库中的id
- **host** ✅:IP/域名
- **createtime** ✅: 云端收录时间
- **uptime** ✅: 云端更新时间
- **local_createtime** ✅: 本地发现时间
- **local_uptime** ✅: 本地更新时间
- **isp** ✅:运营商
- **country** ✅:国家
- **province** ✅:省份
- **city** ✅:城市
- **icp** ✅:ICP备案号
- **icp_owner** ✅:ICP备案主体
- **status** ✅:状态 ``0：疑似资产`` ``1：等待核实`` ``2：确认归属`` ``3：关闭下架`` ``4：忽略`` 
- **handle_status** ✅:处理状态 ``0：待处理`` ``1：处理中`` ``2：下架成功`` ``3：下架失败`` 
- **tags**: 风险标记
- **internet_asset** ✅:是否云上资产 ``1:是`` ``0:否``
- **remarks** ✅:备注
- **details**:端口数据详情
  
  - **id** ✅:端口在数据库中的id
  - **relationsh_info**: 关联证明
  
    - **icon**: 图片线索

      - **img**: 图片base64
      - **md5**: 图片md5
      - **mmh3**: 图片mmh3
  
    - **text**: 文字线索

      - **type**: 内容类型 ``公司全称`` ``公司简称`` ``SSL证书关键字`` ``主域名`` ``ICP备案号``
      - **scope**: 匹配范围 ``标题`` ``正文`` ``证书`` ``Banner``
      - **keyword**: 文字内容
  - **service**: 服务
  - **port**: 端口
  - **title**: 标题
  - **status_code**: 状态码
  - **site_icp**: 站点ICP备案
  - **url**: 站点URL
  - **createtime**: 云端收录时间
  - **uptime**: 云端更新时间
  - **local_createtime**: 本地发现时间
  - **local_uptime**: 本地更新时间
  - **webfp**: 站点指纹
  - **header**: 站点报文头部信息
  - **content**: 站点报文正文
  - **sslinfo**: SSL证书信息
- **keywords**: 文字线索和图片线索mmh3
- **assets_group**：资产组及资产责任人

  - **net**：网络组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  - **app**：应用组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名

.. note:: ✅ 表示该字段可排序
