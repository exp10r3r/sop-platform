文字线索-新增
================

用于新增影子资产监控-文字线索

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/shadow/keywords/text



请求参数
+++++++++++++++++++++

+---------+-----------+----------+----------------------------------------------------------------------+------+
| 字段    | 字段名称  | 是否必填 | 说明                                                                 | 示例 |
+=========+===========+==========+======================================================================+======+
| keyword | 关键字    | 是       |                                                                      |      |
+---------+-----------+----------+----------------------------------------------------------------------+------+
| remarks | 备注      | 否       |                                                                      |      |
+---------+-----------+----------+----------------------------------------------------------------------+------+
| type    | 内容类型  | 是       | 单选，可选值为：公司全称、公司简称、SSL证书关键字、主域名、ICP备案号 |      |
+---------+-----------+----------+----------------------------------------------------------------------+------+
|| scope  || 匹配范围 || 是      || 多选，可选值为：标题、正文、证书、Banner、ICP备案号；               ||     |
||        ||          ||         || 通过数组传参                                                        ||     |
+---------+-----------+----------+----------------------------------------------------------------------+------+

请求示例
++++++++++++++++++++++++++++++++++++++++++++++++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:8000/api/v1/shadow/keywords/text"

    payload = json.dumps({
        "keyword": "xx安全",
        "type": "公司全称",
        "scope": ["正文", "证书"]
    })
    headers = {
        'Accept': 'application/json',
        'Content-type': 'application/json',
        'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
        'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
    }

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)
