图片线索-新增
================

用于新增影子资产监控-图片线索

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/shadow/keywords/icon



请求参数
+++++++++++++++++++++

+------+------------+----------+--------------------------------------------------+------+
| 字段 | 字段名称   | 是否必填 | 说明                                             | 示例 |
+======+============+==========+==================================================+======+
| file | 上传的图片 | 是       | 图片类型支持icon、ico、jpg、png，大小不能大于3MB |      |
+------+------------+----------+--------------------------------------------------+------+

请求示例
++++++++++++++++++++++++++++++++++++++++++++++++++++++
   
.. code-block:: python

    import requests

    url = "http://127.0.0.1:9000/api/v1/shadow/keywords/icon"

    payload = {}
    files=[
        ('file',('xxx.png',open('/xxx.png','rb'),'image/png'))
    ]
    headers = {
        'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
        'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
    }

    response = requests.request("POST", url, headers=headers, data=payload, files=files)

    print(response.text)

=============   ===============   ===============
status          boolean           是否成功
