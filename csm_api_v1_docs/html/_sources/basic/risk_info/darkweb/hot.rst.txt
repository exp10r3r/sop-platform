热点信息-列表
=======================

用于获取暗网监控数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/darkweb/hot



搜索参数
+++++++++++++++++++++

+--------------+--------------+----------+-----------------------------+
| 字段         | 字段名称     | 查询方式 | 说明                        |
+==============+==============+==========+=============================+
| id           | ID           | 精确     |                             |
+--------------+--------------+----------+-----------------------------+
| author       | 发布者       | 模糊     |                             |
+--------------+--------------+----------+-----------------------------+
| title        | 标题         | 模糊     |                             |
+--------------+--------------+----------+-----------------------------+
| content      | 正文         | 模糊     |                             |
+--------------+--------------+----------+-----------------------------+
| url          | 地址         | 模糊     |                             |
+--------------+--------------+----------+-----------------------------+
| publish_time | 信息发布时间 | 范围     | 例如：2020-04-19/2020-09-19 |
+--------------+--------------+----------+-----------------------------+
| capture_time | 信息采集时间 | 范围     | 例如：2020-04-19/2020-09-19 |
+--------------+--------------+----------+-----------------------------+



其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/darkweb?attach=count&id=1&nickname=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **author** ✅：发布者
- **publish_time** ✅：信息发布时间
- **title** ✅：标题
- **content** ✅：正文
- **url** ✅：地址
- **follow** ✅：是否已关注  ``1:是``  ``0:否`` 
- **capture_time** ✅：信息采集时间

.. note:: ✅ 表示该字段可排序
