邮箱列表
=======================

用于获取企业邮箱监控-邮箱列表

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/mails

搜索参数
+++++++++++++++++++++

+-----------------+--------------+----------+-----------------------------+
| 字段            | 字段名称     | 查询方式 | 说明                        |
+=================+==============+==========+=============================+
| id              | ID           | 精确     |                             |
+-----------------+--------------+----------+-----------------------------+
| mail            | 邮箱地址     | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| keywords        | 匹配关键字   | 精确多选 |                             |
+-----------------+--------------+----------+-----------------------------+
| user_id         | 用户ID       | 精确     |                             |
+-----------------+--------------+----------+-----------------------------+
| owner           | 姓名         | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| create_time     | 本地创建时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| update_time     | 本地更新时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| tags            | 标签         | 精确多选 |                             |
+-----------------+--------------+----------+-----------------------------+
| source          | 来源         | 精确多选 |                             |
+-----------------+--------------+----------+-----------------------------+
| expose_count    | 暴露次数     | 精确     | 0：没有暴露，1：有暴露次数  |
+-----------------+--------------+----------+-----------------------------+
| act_pwd         | 账密泄露情况 | 精确     | 0：没有泄露，1：有泄露      |
+-----------------+--------------+----------+-----------------------------+
| createtime      | 云端收录时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| uptime          | 云端更新时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| keyword_remarks | 关键字备注   | 精确多选 |                             |
+-----------------+--------------+----------+-----------------------------+
| assets_group_id | 资产组id     | 精确多选 |                             |
+-----------------+--------------+----------+-----------------------------+

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/mails?user_id=1&keywords=test&attach=count&ordering=-id

Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **mail** ✅：邮箱地址
- **user_id** ✅：用户id
- **owner** ✅：姓名
- **create_time** ✅：本地创建时间
- **update_time** ✅：本地更新时间
- **tags** ：标签
- **source**：来源
- **expose_count** ✅：暴露次数
- **act_pwd**：账密泄露情况
- **keywords**：匹配关键字
- **createtime** ✅：云端收录时间
- **uptime** ✅：云端更新时间
- **assets_group**：资产组及资产责任人

  - **net**：网络组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  - **app**：应用组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名

.. note:: ✅ 表示该字段可排序
