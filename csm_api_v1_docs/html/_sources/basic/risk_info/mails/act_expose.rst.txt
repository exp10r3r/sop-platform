账密泄露情况
===============================

用于获取某个邮箱的账密泄露情况

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/mails/act_expose?mail_id={id}

.. note:: mail_id为邮箱id，即邮箱列表里某个邮箱信息的id，必填

搜索参数
+++++++++++++++++++++

+-------------+----------+----------+-----------------------------+
| 字段        | 字段名称 | 查询方式 | 说明                        |
+=============+==========+==========+=============================+
| id          | ID       | 精确     | 此id为这条账密泄露数据的id  |
+-------------+----------+----------+-----------------------------+
| channel     | 渠道     | 精确     | 1：tg                       |
+-------------+----------+----------+-----------------------------+
| source      | 具体来源 | 模糊     |                             |
+-------------+----------+----------+-----------------------------+
| password    | 密码     | 模糊     |                             |
+-------------+----------+----------+-----------------------------+
| update_time | 更新时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-------------+----------+----------+-----------------------------+

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/mails/act_expose?mail_id=697478&channel=1&attach=count&ordering=-id

Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **mail** ✅：邮箱地址
- **channel** ✅：渠道
- **source** ✅：具体来源
- **password** ✅：密码
- **other** ：其他
- **update_time** ✅：更新时间

.. note:: ✅ 表示该字段可排序
