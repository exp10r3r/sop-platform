关键字-新增
================

用于新增APP资产监控关键字

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/application/keywords



请求参数
+++++++++++++++++++++

+---------+-----------+----------+------------------------------------------------------------------------+-------------------+
| 字段    | 字段名称  | 是否必填 | 说明                                                                   | 示例              |
+=========+===========+==========+========================================================================+===================+
| keyword | 关键字    | 是       |                                                                        |                   |
+---------+-----------+----------+------------------------------------------------------------------------+-------------------+
| type    | 匹配模式  | 是       | 文字模糊匹配、同开发者枚举 2选1                                        |                   |
+---------+-----------+----------+------------------------------------------------------------------------+-------------------+
|| scope  || 匹配内容 || 否      || 匹配模式为文字模糊匹配时才需要填写，可选值：APP名称、开发者名称、详情 || 开发者名称, 详情 |
||        ||          ||         || 多个值以半角逗号分隔                                                  ||                  |
+---------+-----------+----------+------------------------------------------------------------------------+-------------------+
| remarks | 备注      | 否       |                                                                        |                   |
+---------+-----------+----------+------------------------------------------------------------------------+-------------------+

请求示例
++++++++++++++++++++++++++++++++++++++++++++++++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:8000/api/v1/application/keywords"

    payload = json.dumps({
        "keyword": "xx安全",
        "type": "文字模糊匹配",
        "scope": "开发者名称, 详情",
        "remarks": "这是备注"
    })
    headers = {
        'Accept': 'application/json',
        'Content-type': 'application/json',
        'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
        'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
    }

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)
