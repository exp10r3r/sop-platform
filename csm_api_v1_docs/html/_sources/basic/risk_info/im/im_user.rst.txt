用户列表
==================================

用于获取IM监控用户列表数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/im/user


搜索参数
+++++++++++++++++++++

+-----------------+--------------------+----------+--------------------------+
| 字段            | 字段名称           | 查询方式 | 说明                     |
+=================+====================+==========+==========================+
| id              | ID                 | 精确     |                          |
+-----------------+--------------------+----------+--------------------------+
| source          | 消息来源           | 模糊     |                          |
+-----------------+--------------------+----------+--------------------------+
| type            | 类型               | 精确多选 | 例如: user,channel       |
+-----------------+--------------------+----------+--------------------------+
| first_name      | 名                 | 模糊     |                          |
+-----------------+--------------------+----------+--------------------------+
| last_name       | 姓                 | 模糊     |                          |
+-----------------+--------------------+----------+--------------------------+
| username        | 用户名             | 模糊     |                          |
+-----------------+--------------------+----------+--------------------------+
| phone           | 手机号             | 模糊     |                          |
+-----------------+--------------------+----------+--------------------------+
| deleted         | 用户是否已删除     | 精确     |                          |
+-----------------+--------------------+----------+--------------------------+
| related_id      | 用户ID             | 精确     |                          |
+-----------------+--------------------+----------+--------------------------+
| status          | 状态               | 精确多选 | 例如:0,1,2               |
+-----------------+--------------------+----------+--------------------------+
| collection_time | 消息收录时间       | 范围     | 例如:2020-7-20/2020-8-20 |
+-----------------+--------------------+----------+--------------------------+
| up_time         | 消息本地更新时间   | 范围     | 例如:2020-7-20/2020-8-20 |
+-----------------+--------------------+----------+--------------------------+
| create_time     | 消息同步到本地时间 | 范围     | 例如:2020-7-20/2020-8-20 |
+-----------------+--------------------+----------+--------------------------+




其他参数
+++++++++++++++++++++

+---------------+---------------+--------+-----------------------------------------------------+
| 参数          | 参数名称      | 可选值 | 说明                                                |
+===============+===============+========+=====================================================+
|| attach       || 附加项       || count || 可选，传count时，进行统计数量, 并在接口中返回      |
||              ||              ||       || 例如:                                              |
||              ||              ||       || ?attach=count                                      |
+---------------+---------------+--------+-----------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/im/user?attach=count&id=1&keyword=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解:

- **id** ✅:在数据库中的id
- **source** ✅:用户来源
- **type** ✅: 类型 ``user: 用户`` ``channel: 频道`` Telegram中可以以频道的身份在群组中发言
- **first_name** ✅: 名
- **last_name** ✅: 姓
- **username** ✅: 用户名
- **phone** ✅: 手机号
- **deleted** ✅: 用户是否已删除  ``0:否`` ``1:是``
- **related_id** ✅: 用户ID（在Telegram中的ID）
- **collection_time** ✅: 收录时间
- **create_time** ✅:同步到本地时间
- **up_time** ✅:本地更新时间
- **status**:状态 ``0:待确认`` ``1:正在处理`` ``2:存在风险`` ``3:已确认`` ``4:已处理``
- **chat_statis**: 所在群组统计数据
  
  - **id**:群组id
  - **name**:群组名称
  - **count**:用户在群组中发言数量统计

.. note:: ✅ 表示该字段可排序
