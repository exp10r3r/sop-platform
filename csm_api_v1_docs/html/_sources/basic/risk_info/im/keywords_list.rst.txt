关键字-列表
=======================

用于获取IM监控-关键字列表

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/im/keywords



搜索参数
+++++++++++++++++++++

+-----------------+------------+----------+-----------------------------+
| 字段            | 字段名称   | 查询方式 | 说明                        |
+=================+============+==========+=============================+
| id              | ID         | 精确     |                             |
+-----------------+------------+----------+-----------------------------+
| keyword         | 关键字     | 模糊     |                             |
+-----------------+------------+----------+-----------------------------+
| type            | 匹配模式   | 精确     | user/group/keyword          |
+-----------------+------------+----------+-----------------------------+
| remarks         | 备注       | 模糊     |                             |
+-----------------+------------+----------+-----------------------------+
| create_time     | 创建时间   | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+------------+----------+-----------------------------+
| up_time         | 更新时间   | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+------------+----------+-----------------------------+
| user_id         | 用户ID     | 精确     |                             |
+-----------------+------------+----------+-----------------------------+
| username        | 用户名     | 精确     |                             |
+-----------------+------------+----------+-----------------------------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/im/keywords?attach=count&id=1&keyword=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **keyword** ✅：关键字
- **type** ✅：匹配模式  ``user：用户ID``  ``group：群组频道`` ``keyword：消息模糊匹配``
- **user_id** ✅：用户id
- **username** ✅：用户名
- **create_time** ✅：创建时间
- **up_time** ✅：更新时间
- **remarks** ✅：备注

.. note:: ✅ 表示该字段可排序
