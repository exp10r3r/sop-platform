结果列表
=======================

用于获取开源社区监控仓库列表数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/git



搜索参数
+++++++++++++++++++++

+-----------------+--------------+----------+-----------------------------+
| 字段            | 字段名称     | 查询方式 | 说明                        |
+=================+==============+==========+=============================+
| id              | ID           | 精确     |                             |
+-----------------+--------------+----------+-----------------------------+
| source          | 来源         | 精确     |                             |
+-----------------+--------------+----------+-----------------------------+
| project         | 项目名称     | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| project_url     | 项目地址     | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| lang            | 语言         | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| author          | 作者         | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| keywords        | 命中关键字   | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| create_time     | 本地创建时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| local_uptime    | 本地更新时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| created_at      | 项目创建时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| pushed_at       | 项目推送时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| updated_at      | 项目更新时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-----------------+--------------+----------+-----------------------------+
| description     | 项目描述     | 模糊     |                             |
+-----------------+--------------+----------+-----------------------------+
| keyword_remarks | 关键字备注   | 精确多选 |                             |
+-----------------+--------------+----------+-----------------------------+
| assets_group_id | 资产组id     | 精确多选 |                             |
+-----------------+--------------+----------+-----------------------------+



其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/git?attach=count&id=1&nickname=test&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **create_time** ✅：本地创建时间
- **local_uptime** ✅：本地更新时间
- **created_at** ✅：项目创建时间
- **pushed_at** ✅：项目推送时间
- **updated_at** ✅：项目更新时间
- **source** ✅：来源  ``GitHub：github``  ``Gitee：码云``
- **project** ✅：项目名称
- **project_url** ✅：项目地址
- **lang** ✅：语言
- **author** ✅：作者
- **head_url** ✅：作者头像地址
- **keywords** ✅：命中关键字
- **keywords_num**：命中次数 
- **pending_review**：待审阅代码块数量
- **pending_verification**：待核实代码块数量
- **confirmed_leaks**：确认泄露代码块数量
- **false_alarm**：误报代码块数量
- **disposed**：已处置代码块数量
- **emails**：提交者邮箱信息
- **description**: 项目描述
- **assets_group**：资产组及资产责任人

  - **net**：网络组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  - **app**：应用组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  
.. note:: ✅ 表示该字段可排序
