详情列表
==========================

用于获取开源社区监控数据的代码块列表
对应的Web页面中快速排查按钮所看到的内容

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/git/{id}

.. note:: id是结果列表(/api/v1/git)中的id


搜索参数
+++++++++++++++++++++

+-------------+----------+----------+-----------------------------+
| 字段        | 字段名称 | 查询方式 | 说明                        |
+=============+==========+==========+=============================+
| id          | ID       | 精确     |                             |
+-------------+----------+----------+-----------------------------+
| status      | 处置状态 | 精确多选 |                             |
+-------------+----------+----------+-----------------------------+
| create_time | 创建时间 | 时间范围 | 例如：2020-04-19/2020-09-19 |
+-------------+----------+----------+-----------------------------+



其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/git/123?attach=count&id=1&status=1,2,3&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **file_url** ✅：文件url
- **code** ✅：代码块
- **create_time** ✅：发现时间
- **processing_time** ✅：处置时间
- **status** ✅：状态 ``1 待确认 `` ``2 正在处理`` ``3 已确认`` ``4 忽略 `` ``5 已处理`` 
- **remarks** ✅：备注
- **type** ✅：分类 ``1 业务代码`` ``2 敏感文档`` ``3 敏感配置`` ``4 人员信息`` 
- **keywords**：命中关键字

.. note:: ✅ 表示该字段可排序
