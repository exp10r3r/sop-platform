新增
================

用于新增端口模板

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/template/port



请求参数
+++++++++++++++++++++

+-------+----------+----------+------+------+
| 字段  | 字段名称 | 是否必填 | 说明 | 示例 |
+=======+==========+==========+======+======+
| name  | 模板名称 | 是       |      |      |
+-------+----------+----------+------+------+
| value | 端口值   | 是       |      |      |
+-------+----------+----------+------+------+

请求示例
++++++++++++++++++++++++++++++++++++++++++++++++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:8000/api/v1/template/port"

    payload = json.dumps({
        "name": "端口模板1",
        "value": "1,2,3,2221"
    })
    headers = {
        'Accept': 'application/json',
        'Content-type': 'application/json',
        'ACCESSKEY': 'ijE80piSATBYT8qVQc1InSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
        'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ31uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
    }

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)

Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            dict              返回数据
=============   ===============   ===============


示例值
+++++++++

.. code-block:: javascript

    {
        "status": true,
        "data": {
            "id": 43,
            "value": "1,2,3,2221",
            "name": "端口模板1"
        },
        "login_status": true
    }

+++++++++

                "该字段是必填项。"
