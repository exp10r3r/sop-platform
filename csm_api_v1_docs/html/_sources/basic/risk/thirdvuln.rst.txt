第三方漏洞
================

用于获取第三方漏洞数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/thirdvuln

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/thirdvuln?attach=count&id=1&ip=1.1.1.1&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **collector_type** ✅：漏洞来源类型
- **title** ✅：漏洞名称
- **ip** ✅：漏洞地址
- **port** ✅：端口
- **risklevel** ✅：漏洞等级 ``0:信息`` ``1:低危`` ``2:中危`` ``3:高危`` ``4:严重``
- **type** ✅：漏洞类型
- **description** ✅：漏洞描述
- **solution** ✅：解决方案
- **seealso** ✅：参考链接
- **first_time** ✅：首次发现时间（扫描器中）
- **last_time** ✅：最后发现时间（扫描器中）
- **up_time** ✅：更新时间（CSM）
- **create_time** ✅：创建时间（CSM）
- **status** ✅：漏洞变化状态 ``0：遗留`` ``1：新增`` ``3：减少`` 
- **cve** ✅：CVE编号
- **cpe** ✅：CPE
- **cnnvd** ✅：CNNVD编号
- **poc**：是否有poc  ``1:是`` ``0：否``
- **exp**：是否有exp  ``1:是`` ``0：否``
- **rce**：是否有rce  ``1:是`` ``0：否``
- **remarks** ✅：备注
- **assets_group**：资产组及资产责任人

  - **net**：网络组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  - **app**：应用组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
- **handle_status** ✅：漏洞处置状态 ``0：未处理`` ``1：已确认`` ``2：已修复`` ``3：误报`` ``4：待修复`` ``5：修复失败`` ``6：已验证`` ``7：忽略`` 
- **handler_id** ✅：处理人id
- **handler** ✅：处理人
- **vulinfo** ✅：验证信息
- **taskids**：任务id
- **cvss** ✅：CVSS
- **cvss_vector** ✅：CVSS向量
- **vprscore** ✅：VPR评分
- **vprcontext** ✅：VPR
  
.. note:: ✅ 表示该字段可排序
