PoC漏洞
================

用于获取PoC漏洞数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/poc

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/poc?attach=count&id=1&target=1.1.1.1&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **vul_title** ✅：漏洞名称
- **risklevel** ✅：漏洞等级 ``0:低危`` ``1:中危`` ``2:高危`` ``3:严重``
- **vul_type** ✅：漏洞类型
- **target** ✅：漏洞地址
- **ip** ✅：IP地址
- **port** ✅：端口
- **change_state** ✅：漏洞变化状态 ``0：遗留`` ``1：新增`` ``3：减少`` 
- **status** ✅：漏洞处置状态 ``0：未处理`` ``1：已确认`` ``2：已修复`` ``3：误报`` ``4：待修复`` ``5：修复失败`` ``6：已验证`` ``7：忽略`` 
- **rce** ✅：是否有rce  ``1:是`` ``0：否``
- **cve** ✅：CVE编号
- **cnnvd** ✅：CNNVD编号
- **bugtraq** ✅：bugtraq编号
- **vul_description** ✅：漏洞描述
- **vulinfo** ✅：验证信息
- **vul_solution** ✅：解决方案
- **url** ✅：参考链接
- **remarks** ✅：备注
- **assets_group**：资产组及资产责任人

  - **net**：网络组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  - **app**：应用组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
- **createtime** ✅：首次时间
- **uptime** ✅：最后发现时间
- **handler_id** ✅：处理人id
- **handler** ✅：处理人
- **taskids**：任务id
- **verify_state**：复扫状态 ``0:未在复扫``  ``1:复扫中``  ``2:复扫完成``  ``3:复扫失败``
- **plugin_id** ✅：扫描插件ID
- **tags** ：风险标签
  
.. note:: ✅ 表示该字段可排序
