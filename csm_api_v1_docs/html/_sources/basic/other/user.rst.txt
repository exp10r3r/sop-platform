用户列表
===========================

用于获取用户列表数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/user



搜索参数
+++++++++++++++++++++

+--------------------+--------------+----------+---------------------------+
| 字段               | 字段名称     | 查询方式 | 说明                      |
+====================+==============+==========+===========================+
| id                 | id           | 精确     |                           |
+--------------------+--------------+----------+---------------------------+
| username           | 用户名       | 模糊     |                           |
+--------------------+--------------+----------+---------------------------+
| nickname           | 昵称         | 模糊     |                           |
+--------------------+--------------+----------+---------------------------+
| role               | 角色id       | 精确     |                           |
+--------------------+--------------+----------+---------------------------+
| remarks            | 备注         | 模糊     |                           |
+--------------------+--------------+----------+---------------------------+
| email_notice       | 是否邮件通知 | 精确     |                           |
+--------------------+--------------+----------+---------------------------+
| email              | 邮箱地址     | 模糊     |                           |
+--------------------+--------------+----------+---------------------------+
| de_id              | 部门id       | 精确     |                           |
+--------------------+--------------+----------+---------------------------+
| phone              | 手机号       | 模糊     |                           |
+--------------------+--------------+----------+---------------------------+
| last_login_address | 最近登录地址 | 模糊     |                           |
+--------------------+--------------+----------+---------------------------+
| last_login_ip      | 最近登录IP   | 模糊     |                           |
+--------------------+--------------+----------+---------------------------+
| last_login         | 最近登录时间 | 范围     | 例如：2020-7-20/2020-8-20 |
+--------------------+--------------+----------+---------------------------+
| use_time           | 有效期       | 范围     | 例如：2020-7-20/2020-8-20 |
+--------------------+--------------+----------+---------------------------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/user?attach=count&id=1&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解:

- **id** ✅: 在数据库中的id
- **username** ✅: 用户名
- **nickname** ✅: 昵称
- **role** ✅: 角色id
- **remarks** ✅: 备注
- **email_notice** ✅: 是否邮件通知 ``1:是`` ``0:否``
- **email** ✅: 邮箱地址
- **de_id** ✅: 部门id
- **department**: 部门名称
- **phone** ✅: 手机号
- **use_time** ✅: 有限期
- **use_status**:可用状态 ``1:正常`` ``0:不可用``
- **last_login_ip** ✅: 最近登录IP
- **last_login_address** ✅: 最近登录地址
- **last_login** ✅: 最近登录时间
- **accesskey**: API accesskey
- **secretkey**: API secretkey

.. note:: ✅ 表示该字段可排序
