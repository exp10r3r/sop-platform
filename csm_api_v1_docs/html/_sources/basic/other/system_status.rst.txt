系统运行信息
===========================

用于获取系统运行信息数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/system_status

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/system_status

Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
=============   ===============   ===============

数据字段详解:

- **hostname**：设备名称
- **version**：版本
- **run_time**：运行时长
- **start_time**：最近一次启动时间

- **memory**：物理内存信息

  - **total**：总内存
  - **percent**：内存利用率
  - **used**：已用内存
  - **free**：剩余内存

- **swap**：交换内存信息

  - **total**：总内存
  - **percent**：内存利用率
  - **used**：已用内存
  - **free**：剩余内存

- **disk_partitions**：磁盘信息

  - **device**：文件系统
  - **mountpoint**：挂载名称
  - **total**：总空间
  - **used**：已用空间
  - **free**：剩余空间
  - **percent**：磁盘利用率

- **cpu_loadavg**：CPU信息

  - **core**：核心数
  - **logical_core**：线程数
  - **loadavg**：过去1分钟、5分钟和15分钟内的系统负载平均值
  - **percent**：CPU负载百分比
  - **loadavg_level**：CPU负载等级，``1：正常``，``2：迟缓``，``3：严重超负荷``
  - **cpu_usage**：CPU利用率
