SSL证书
================

用于获取SSL证书资产数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/ssl_cert



搜索参数
+++++++++++++++++++++

+---------------------+------------------+----------+---------------------------+
| 字段                | 字段名称         | 查询方式 | 说明                      |
+=====================+==================+==========+===========================+
| id                  | id               | 精确     |                           |
+---------------------+------------------+----------+---------------------------+
| cn                  | 使用者           | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| o                   | 使用组织         | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| issuer_cn           | 颁发机构         | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| issuer_o            | 颁发组织         | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| ips                 | 关联IP           | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| domains             | 关联域名         | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| encryption          | 加密算法         | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| version             | 版本             | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| valid_time          | 有效期           | 范围     | 例如：2020-7-20/2020-8-20 |
+---------------------+------------------+----------+---------------------------+
| create_time         | 创建时间         | 范围     | 例如：2020-7-20/2020-8-20 |
+---------------------+------------------+----------+---------------------------+
| up_time             | 更新时间         | 范围     | 例如：2020-7-20/2020-8-20 |
+---------------------+------------------+----------+---------------------------+
| serial_number       | 序列号           | 模糊     |                           |
+---------------------+------------------+----------+---------------------------+
| days_left_to_expire | 有效期小于多少天 | 精确     |                           |
+---------------------+------------------+----------+---------------------------+
|| expired            || 是否已过期      || 单选    || 0：否                    |
||                    ||                 ||         || 1：是                    |
+---------------------+------------------+----------+---------------------------+

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+


请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/ssl_cert?attach=count&cn=tapd&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **cn** ✅：使用者
- **o** ✅：使用组织
- **issuer_cn** ✅：颁发机构
- **issuer_o** ✅：颁发组织
- **ips**：关联ip
- **domains**：关联域名
- **encryption** ✅：加密算法
- **version** ✅：版本
- **valid_time** ✅：有效期
- **create_time** ✅：创建时间
- **up_time** ✅：更新时间
- **serial_number** ✅：序列号

.. note:: ✅ 表示该字段可排序
