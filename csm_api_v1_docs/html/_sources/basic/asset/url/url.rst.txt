URL/API列表
====================

用于获取URL/API资产的URL/API列表数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/url



搜索参数
+++++++++++++++++++++

+----------------------+----------------+-----------+---------------------------+
| 字段                 | 字段名称       | 查询方式  | 说明                      |
+======================+================+===========+===========================+
| id                   | id             | 精确      |                           |
+----------------------+----------------+-----------+---------------------------+
| create_time          | 创建时间       | 范围      | 例如：2020-7-20/2020-8-20 |
+----------------------+----------------+-----------+---------------------------+
| uptime               | 更新时间       | 范围      | 例如：2020-7-20/2020-8-20 |
+----------------------+----------------+-----------+---------------------------+
| source               | 资产来源       | 精确多选  | 例如:主动扫描,阿里云      |
+----------------------+----------------+-----------+---------------------------+
| host                 | Host           | 模糊      |                           |
+----------------------+----------------+-----------+---------------------------+
| port                 | 端口           | 精确      |                           |
+----------------------+----------------+-----------+---------------------------+
| method               | Method         | 精确      |                           |
+----------------------+----------------+-----------+---------------------------+
| url                  | URL地址        | 模糊      |                           |
+----------------------+----------------+-----------+---------------------------+
| path                 | Path           | 模糊      |                           |
+----------------------+----------------+-----------+---------------------------+
| parameter            | 请求参数       | 模糊      |                           |
+----------------------+----------------+-----------+---------------------------+
| response_code        | 状态码         | 精确      |                           |
+----------------------+----------------+-----------+---------------------------+
| title                | 标题           | 模糊      |                           |
+----------------------+----------------+-----------+---------------------------+
| assets_group_id      | 资产组id       | 精确多选  |                           |
+----------------------+----------------+-----------+---------------------------+
| assets_group_user_id | 资产组责任人id | 精确多选  |                           |
+----------------------+----------------+-----------+---------------------------+
| request_raw          | 请求原文       | 模糊      |                           |
+----------------------+----------------+-----------+---------------------------+
| response_raw         | 响应原文       | 模糊      |                           |
+----------------------+----------------+-----------+---------------------------+
| taskids              | 任务id         | 精确多选  |                           |
+----------------------+----------------+-----------+---------------------------+
|| has_params          || 是否有参数    || 精确单选 || 0：不带参数              |
||                     ||               ||          || 1：带参数                |
+----------------------+----------------+-----------+---------------------------+

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/url?attach=count&id=1&ip=1.1.1.1&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **uptime** ✅：更新时间
- **createtime** ✅：创建时间
- **source**：来源
- **host** ✅：Host
- **port** ✅：端口
- **method** ✅：Method
- **url** ✅：URL地址
- **path** ✅：Path
- **parameter** ✅：请求参数
- **response_code** ✅：状态码
- **title** ✅：Title
- **assets_group**：资产组及资产责任人

  - **net**：网络组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  - **app**：应用组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
- **request_raw** ✅：请求原文
- **response_raw ✅**：响应原文
- **taskids**：任务id

.. note:: ✅ 表示该字段可排序
