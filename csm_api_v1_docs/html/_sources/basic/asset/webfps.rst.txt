分类资产库
================

用于获取分类资产库数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/webfps



搜索参数
+++++++++++++++++++++

+----------------------+----------------+----------+---------------------------+
| 字段                 | 字段名称       | 查询方式 | 说明                      |
+======================+================+==========+===========================+
| id                   | id             | 精确     |                           |
+----------------------+----------------+----------+---------------------------+
| target               | 资产           | 模糊     |                           |
+----------------------+----------------+----------+---------------------------+
| port                 | 关联端口       | 模糊     |                           |
+----------------------+----------------+----------+---------------------------+
| type                 | 一级分类       | 模糊     |                           |
+----------------------+----------------+----------+---------------------------+
| type_id              | 一级分类id     | 精确     |                           |
+----------------------+----------------+----------+---------------------------+
| cat                  | 二级分类       | 模糊     |                           |
+----------------------+----------------+----------+---------------------------+
| catid                | 二级分类id     | 精确     |                           |
+----------------------+----------------+----------+---------------------------+
| app_name             | 指纹名称       | 模糊     |                           |
+----------------------+----------------+----------+---------------------------+
| app_verison          | 附加信息       | 模糊     |                           |
+----------------------+----------------+----------+---------------------------+
| assets_group_id      | 资产组id       | 精确多选 |                           |
+----------------------+----------------+----------+---------------------------+
| assets_group_user_id | 资产组责任人id | 精确多选 |                           |
+----------------------+----------------+----------+---------------------------+
| remarks              | 备注           | 模糊     |                           |
+----------------------+----------------+----------+---------------------------+
| uptime               | 更新时间       | 范围     | 例如：2020-7-20/2020-8-20 |
+----------------------+----------------+----------+---------------------------+
| createtime           | 更新时间       | 范围     | 例如：2020-7-20/2020-8-20 |
+----------------------+----------------+----------+---------------------------+


其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+

请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/webfps?attach=count&id=1&ip=1.1.1.1&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============

数据字段详解：

- **id** ✅：在数据库中的id
- **target** ✅：资产
- **port** ✅：关联端口
- **cat** ✅：二级分类
- **catid** ✅：二级分类id
- **type** ：一级分类
- **type_id** ：一级分类id
- **app_name** ✅：指纹名称
- **app_version** ✅：附加信息
- **remarks** ✅：备注
- **uptime** ✅：更新时间
- **createtime** ✅：更新时间
- **assets_group**：资产组及资产责任人

  - **net**：网络组

    - **id**：网络组id
    - **name**：网络组名称
    - **resposibler**：责任人用户名
  - **app**：应用组

    - **id**：网络组id 
    - **name**：网络组名称
    - **resposibler**：责任人用户名
- **taskids** ✅：任务id

.. note:: ✅ 表示该字段可排序
