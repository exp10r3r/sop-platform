疑似网站历史检测记录截图
========================

用于获取疑似网站历史检测记录截图

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/fake/web/check/screenshot

请求参数
+++++++++++++++++++++

+------------------+--------------+----------+----------------------------+--------------+
| 字段             | 字段名称     | 是否必填 | 说明                       | 示例         |
+==================+==============+==========+============================+==============+
| id               | 检测记录ID   |  是      |                            |              |
+------------------+--------------+----------+----------------------------+--------------+
| screenshot_type  | 检测方式     |  是      | 1：国内  2：境外           |              |
+------------------+--------------+----------+----------------------------+--------------+


请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/fake/web/check/screenshot?id=201&screenshot_type=1
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============


数据字段详解：

- **screenshot** ：截图base64编码

+++++++++

        "status": true
    }
