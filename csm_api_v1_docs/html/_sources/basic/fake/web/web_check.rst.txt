疑似网站历史检测记录
====================

用于获取疑似网站历史检测记录

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   GET /api/v1/fake/web/check

请求参数
+++++++++++++++++++++

+---------------+--------------+----------+----------------------------+--------------+
| 字段          | 字段名称     | 是否必填 | 说明                       | 示例         |
+===============+==============+==========+============================+==============+
| web_id        | 网站ID       |  是      |                            |              |
+---------------+--------------+----------+----------------------------+--------------+


搜索参数
+++++++++++++++++++++

+-------------------+------------------+-----------+---------------------------+
| 字段              | 字段名称         | 查询方式  | 说明                      |
+===================+==================+===========+===========================+
| id                | ID               | 精确      |                           |
+-------------------+------------------+-----------+---------------------------+
| web_id            | 网站ID           | 精确      |                           |
+-------------------+------------------+-----------+---------------------------+
| check_time        | 检测时间         | 范围      | 例如：2020-7-20/2020-8-20 |
+-------------------+------------------+-----------+---------------------------+
| domestic_result   | 国内检测结果     | 精确      |  0：未知 1：存活 2：失效  |
+-------------------+------------------+-----------+---------------------------+
| foreign_result    | 境外检测结果     | 精确      |  0：未知 1：存活 2：失效  |
+-------------------+------------------+-----------+---------------------------+

其他参数
+++++++++++++++++++++

+---------+----------+--------+------------------------------------------------+
| 参数    | 参数名称 | 可选值 | 说明                                           |
+=========+==========+========+================================================+
|| attach || 附加项  || count || 可选，传count时，进行统计数量, 并在接口中返回 |
||        ||         ||       || 例如:                                         |
||        ||         ||       || ?attach=count                                 |
+---------+----------+--------+------------------------------------------------+


请求示例
+++++++++

.. code-block:: bash

   https://localhost:38201/api/v1/fake/web/check?web_id=561&attach=count&ordering=-id
   
   
Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            array             返回数据
count           integer           总数（当请求参数attach=count存在时）
=============   ===============   ===============


数据字段详解：

- **id** ✅：在数据库中的id
- **web_id** ✅：网站ID
- **check_time** ✅：检测时间
- **domestic_result** ✅：国内检测结果
- **foreign_result** ✅：境外检测结果

.. note:: ✅ 表示该字段可排序


示例值
+++++++++

.. code-block:: javascript

    {
        "info": [
            {
                "id": 193,
                "web_id": 561,
                "domestic_result": 1,
                "foreign_result": 0,
                "check_time": "2025-05-22 14:25:39"
            }
        ],
        "status": true,
        "count": 1
    }
