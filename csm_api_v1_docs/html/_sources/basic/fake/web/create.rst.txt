录入疑似网站
================

用于录入疑似网站数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/fake/web

请求参数
+++++++++++++++++++++

+-------------------+------------------+-----------+------------+---------------------+
| 字段              | 字段名称         | 是否必填  | 说明       | 示例                |
+===================+==================+===========+============+=====================+
| discover_time     | 发现时间         | 否        |            | 2024-10-18 10:03:34 |
+-------------------+------------------+-----------+------------+---------------------+
| domain            | 钓鱼网站域名     | 是        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| url               | 钓鱼网站URL      | 是        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| ip                | 钓鱼网站IP       | 是        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| befaked_domain    | 被仿冒的网站域名 | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| institution_short | 被仿冒的机构名称 | 是        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| institution_code  | 被仿冒的机构代码 | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| target_industry   | 被仿冒的行业代码 | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| provider          | 服务商           | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| country           | 归属国家编码     | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| province          | 归属省份编码     | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| city              | 归属城市编码     | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| fake_ip_info      | 钓鱼网站备案信息 | 否        |            |                     |
+-------------------+------------------+-----------+------------+---------------------+
| screenshot        | 网站截图         | 否        | base64编码 |                     |
+-------------------+------------------+-----------+------------+---------------------+

请求示例
+++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:38202/api/v1/fake/web"

    payload = json.dumps({
        "discover_time": "2020-12-12 22:30:01",
        "domain": "aa.ban1111k.com",
        "url": "http://www.aa.bank.com",
        "ip": "123.12.14.34",
        "befaked_domain": "bank.com",
        "institution_short": "xx银行",
        "institution_code": "X0009H23201234",
        "target_industry": "YH(银行)",
        "provider": "XX服务商",
        "country": "CHN",
        "province": "110000",
        "city": "110101",
        "fake_ip_info": "京ICP证123456号",
        "screenshot": "" # base64.b64encode(img_binary).decode(encoding="utf-8")
    })

    headers = {
        'ACCESSKEY': 'B6xsfMw2SztH3YTv5bWLHynfciajICMgNWomlFOhn14xcssRQQk0Q',
        'SECRETKEY': 'FhfAkrtBNnjRHQdnF0H0JiDeHykb0tQb0JlLSFu9v92Tp31i3M22EaIMSVIKqi8lk',
        'Content-Type': 'application/json',
        'Cookie': 'sessionid=4dw4q32m1i9b98mmb7ymuynm0ol8jjfs'
    }

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)
