处置疑似APP
================

用于处置疑似APP

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   PUT /api/v1/fake/app/handle_status



请求参数
+++++++++++++++++++++

+-------------------+-------------------+-----------+---------------------------+------+
| 字段              | 字段名称          | 是否必填  | 说明                      | 示例 |
+===================+===================+===========+===========================+======+
| id                | ID                | 是        | 需要处置的id列表          |      |
+-------------------+-------------------+-----------+---------------------------+------+
|| status           || 处置状态         || 是       || 可选值:                  |      |
||                  ||                  ||          || 2：正在处理              |      |
||                  ||                  ||          || 3：已确认                |      |
||                  ||                  ||          || 4：忽略                  |      |
||                  ||                  ||          || 5：已处理                |      |
+-------------------+-------------------+-----------+---------------------------+------+

+++++++++

Response
~~~~~~~~

响应参数
++++++++++++

=============   ===============   ===============
参数             类型             描述
=============   ===============   ===============
status          boolean           是否成功
info            string/dict       返回结果信息
=============   ===============   ===============


示例值
+++++++++

.. code-block:: javascript

    {
        "info": "操作成功",
        "status": true
    }


失败示例
+++++++++

.. code-block:: javascript

    {
        "info": {
            "status": "status参数错误"
        },
        "status": false
    }
