录入疑似社交媒体
================

用于录入疑似社交媒体数据

Request
~~~~~~~~

请求地址
+++++++++

.. code-block:: bash

   POST /api/v1/fake/official

请求参数
+++++++++++++++++++++

+-------------------+------------------+-----------+------+---------------------+
| 字段              | 字段名称         | 是否必填  | 说明 | 示例                |
+===================+==================+===========+======+=====================+
| discover_time     | 发现时间         | 否        |      | 2024-10-18 10:03:34 |
+-------------------+------------------+-----------+------+---------------------+
| name              | 仿冒媒体名称     | 是        |      |                     |
+-------------------+------------------+-----------+------+---------------------+
| account_id        | 仿冒媒体编号     | 否        |      |                     |
+-------------------+------------------+-----------+------+---------------------+
| befaked_name      | 被仿冒媒体名称   | 否        |      |                     |
+-------------------+------------------+-----------+------+---------------------+
| institution_short | 被仿冒的机构名称 | 是        |      |                     |
+-------------------+------------------+-----------+------+---------------------+
| institution_code  | 被仿冒的机构代码 | 否        |      |                     |
+-------------------+------------------+-----------+------+---------------------+
| target_industry   | 被仿冒的行业代码 | 否        |      |                     |
+-------------------+------------------+-----------+------+---------------------+
| provider          | 服务商           | 否        |      |                     |
+-------------------+------------------+-----------+------+---------------------+

请求示例
+++++++++
   
.. code-block:: python

    import requests
    import json

    url = "http://127.0.0.1:38202/api/v1/fake/official"

    payload = json.dumps({
        "discover_time": "2020-08-12 00:00:00",
        "name": "xx基金",
        "account_id": "gh_123445",
        "befaked_name": "xx基金",
        "institution_short": "xx基金",
        "institution_code": "X0009H23201234",
        "target_industry": "YH(银行)",
        "provider": "XX服务商"
    })

    headers = {
        'ACCESSKEY': 'B6xsfMw2SztH3YTv5bWLHynfciajICMgNWomlFOhn14xcssRQQk0Q',
        'SECRETKEY': 'FhfAkrtBNnjRHQdnF0H0JiDeHykb0tQb0JlLSFu9v92Tp31i3M22EaIMSVIKqi8lk',
        'Content-Type': 'application/json',
        'Cookie': 'sessionid=4dw4q32m1i9b98mmb7ymuynm0ol8jjfs'
    }

    response = requests.request("POST", url, headers=headers, data=payload)

    print(response.text)
