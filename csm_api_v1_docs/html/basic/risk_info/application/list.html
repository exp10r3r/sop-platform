其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/application?attach=count&id=1&nickname=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解:

  • id ✅:在数据库中的id

  • title ✅:标题

  • keywords:关键字

  • link ✅:链接

  • source ✅:来源

  • version ✅:版本号

  • developer ✅:开发者

  • developer_link ✅:开发者链接

  • rating:评分

  • down_count:下载量 （字符串，非整数，可能存在“5 亿次安装”类似值）

  • remarks ✅:备注

  • seller_link ✅:开发者网站

  • description ✅:简介

  • tags:标签

  • status:处理状态 0:待确认 1:确认归属 2:忽略 3:关停下架 4:仿冒资产

  • relationsh_info:关联证明

    • type:匹配模式

    • scope:匹配内容

    • createtime:添加时间

    • keyword:关键字

  • uptime ✅:云端更新时间

  • createtime ✅:云端收录时间

  • local_uptime ✅：本地更新时间

  • local_create_time ✅：本地创建时间

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

Note

✅ 表示该字段可排序
