我的关注-列表

用于获取暗网监控数据

Request

请求地址

GET /api/v1/darkweb

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

author

发布者

模糊

title

标题

模糊

content

正文

模糊

url

地址

模糊

keyword

模糊

publish_time

原始发布时间

范围

例如：2020-04-19/2020-09-19

capture_time

云端收录时间

范围

本地创建时间

范围

local_uptime

范围

keyword_remarks

精确多选

assets_group_id

资产组id

精确多选

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/darkweb?attach=count&id=1&nickname=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • author ✅：发布者

  • keyword ✅：关键词

  • relationsh_info：关联证明

    • scope：关联范围

    • keyword：关联关键字

  • title ✅：标题

  • content ✅：正文

  • url ✅：地址

  • status ✅：处理状态 0:待确认 1:已确认 2:已处理 3:忽略 5:正在处理

  • publish_time ✅：原始发布时间

  • capture_time ✅：云端收录时间

  • local_uptime ✅：本地更新时间

  • local_createtime ✅：本地创建时间

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

Note

✅ 表示该字段可排序
