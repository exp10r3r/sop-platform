对话列表

用于获取IM监控对话列表数据

Request

请求地址

GET /api/v1/im

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

keyword

关键字

模糊

source

消息来源

模糊

chat_name

群组/频道名称

模糊

chat_type

群组/频道类型

精确多选

例如: group,channel

chat_id

群组/频道id

精确

status

状态

精确多选

例如:0,1,2

collection_time

消息收录时间

范围

例如:2020-7-20/2020-8-20

up_time

消息本地更新时间

范围

例如:2020-7-20/2020-8-20

create_time

消息同步到本地时间

范围

例如:2020-7-20/2020-8-20

keyword_remarks

关键字备注

精确多选

其他参数

参数

参数名称

可选值

说明
all_msg_info
返回所有信息
1
每条数据中，msg_info字段是一段时间内聊天消息的汇总
当传值1时，msg_info字段返回所有消息内容
不传值或传0时，默认仅返回命中的消息
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/im?attach=count&id=1&keyword=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解:

  • id ✅:在数据库中的id

  • source ✅:消息来源

  • chat_id ✅:群组/频道id（在Telegram中的id）

  • chat_info:群组/频道相关信息

    • id:在数据库中的id

    • name:群组/频道名称

    • type:类型 group: 群组 channel:频道

    • participants:群成员/订阅人数

    • photo:群组/频道头像图片base64

    • monitor:是否已关注该群组/频道 1:是 0:否

    • related_id:群组/频道id（在Telegram中的id）

    • desc:群组/频道简介

    • link:群组/频道链接

    • collection_time:群组/频道收录时间

    • latest_msg_time:群组/频道最新消息时间

  • collection_time ✅:消息收录时间

  • create_time ✅:消息同步到本地时间

  • up_time ✅:消息本地更新时间(预留字段，一般无变化)

  • status:状态 0:待审核 1:待核实 2:存在风险

  • msg_info:对话消息列表

    • hit: 是否命中关键字 1:是 0:否

    • type: 消息类型 text: 文本消息 media: 媒体文件

    • msg: 消息内容，数组或文本格式。当格式为数组时，一般是媒体文件内容解析后，进行关键字匹配命中的相关内容。

    • time: 消息发布时间

    • msg_id: 消息id

    • sender: 消息发送者信息；当类型为频道时，本字段为空

      • id: 发送者ID

      • type: 类型 user: 用户 channel: 频道 Telegram中可以以频道的身份在群组中发言

      • phone: 手机号

      • deleted: 用户是否已删除

      • username: 用户名

      • last_name: 姓

      • first_name: 名

  • keyword ✅:关键字

Note

✅ 表示该字段可排序
