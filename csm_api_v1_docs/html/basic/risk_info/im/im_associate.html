查询关联消息接口

用于获取IM监控，对话上下文的接口

Request

请求地址

GET /api/v1/im/associate_msg

搜索参数

无

其他参数

参数

参数名称

可选值

说明

chat_id

群组id（群组表中related_id）

msg_id

消息id（msg_info列表中ID）
option
查询操作
next、previous、current
current:查询包含当前msg_id的一批消息
previous:查询前一批关联消息
next:查询后一批关联消息

请求示例

https://localhost:38201/api/v1/im/associate_msg?attach=count&id=1&keyword=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

数据字段详解:

  • id ✅:在数据库中的id

  • chat_id ✅: 群组/频道ID（在Telegram中的ID）

  • chat_type ✅: 类型 group: 群组 channel: 频道

  • create_time ✅: 收录时间

  • msg_info: 最新收录50条消息列表

    • type: 消息类型 text: 文本消息 media: 媒体文件

    • msg: 消息内容，数组或文本格式。当格式为数组时，一般是媒体文件内容解析后，进行关键字匹配命中的相关内容。

    • time: 消息发布时间

    • msg_id: 消息id

    • sender: 消息发送者信息；当类型为频道时，本字段为空

      • id: 发送者ID

      • type: 类型 user: 用户 channel: 频道 Telegram中可以以频道的身份在群组中发言

      • phone: 手机号

      • deleted: 用户是否已删除

      • username: 用户名

      • last_name: 姓

      • first_name: 名

Note

✅ 表示该字段可排序
