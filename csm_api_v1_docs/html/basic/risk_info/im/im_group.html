群组频道列表

用于获取IM监控群组频道数据

Request

请求地址

GET /api/v1/im/group

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

source

来源

模糊

related_id

群组ID

精确

name

名称

模糊

type

类型

精确多选

例如: group,channel

desc

简介

模糊

status

状态

精确多选

例如:0,1,2

latest_msg_time

最新消息发布时间

范围

例如:2020-7-20/2020-8-20

collection_time

消息收录时间

范围

例如:2020-7-20/2020-8-20

up_time

消息本地更新时间

范围

例如:2020-7-20/2020-8-20

create_time

消息同步到本地时间

范围

例如:2020-7-20/2020-8-20

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/im/group?attach=count&id=1&keyword=test&ordering=-id

参数

类型

数据字段详解:

  • id ✅:在数据库中的id

  • source ✅:来源

  • related_id ✅: 群组/频道ID（在Telegram中的ID）

  • name ✅: 名称

  • participants: 订阅人数

  • type ✅: 类型 group: 群组 channel: 频道

  • desc ✅: 简介

  • last_msg_time ✅: 最新消息发布时间

  • collection_time ✅: 收录时间

  • create_time ✅:同步到本地时间

  • up_time ✅:本地更新时间

  • status:状态 0:待确认 1:正在处理 2:存在风险 3:已确认 4:已处理

  • msg_info: 最新收录50条消息列表

    • type: 消息类型 text: 文本消息 media: 媒体文件

    • msg: 消息内容，数组或文本格式。当格式为数组时，一般是媒体文件内容解析后，进行关键字匹配命中的相关内容。

    • time: 消息发布时间

    • msg_id: 消息id

    • sender: 消息发送者信息；当类型为频道时，本字段为空

      • id: 发送者ID

      • type: 类型 user: 用户 channel: 频道 Telegram中可以以频道的身份在群组中发言

      • phone: 手机号

      • deleted: 用户是否已删除

      • username: 用户名

      • last_name: 姓

      • first_name: 名

  • photo:群组/频道头像图片base64

  • link:群组/频道链接

Note

✅ 表示该字段可排序
