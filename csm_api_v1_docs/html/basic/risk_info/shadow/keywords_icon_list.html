图片线索-列表

用于获取影子资产监控-关键字-图片线索列表

Request

请求地址

GET /api/v1/shadow/keywords/icon

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

keyword

关键字

模糊

remarks

备注

模糊

mmh3

mmh3值

模糊

md5

md5值

模糊

user_id

用户ID

精确

username

用户名

精确

create_time

创建时间

时间范围

例如：2020-04-19/2020-09-19

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/shadow/keywords?attach=count&id=1&keyword=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • keyword ✅：图片线索的base64编码

  • mmh3 ✅：mmh3值

  • md5 ✅：md5值

  • create_time ✅：创建时间

  • remarks ✅：备注

  • user_id ✅：用户id

  • username ✅：用户名

Note

✅ 表示该字段可排序
