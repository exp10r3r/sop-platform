其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/app?attach=count&id=1&nickname=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • keywords：关键字

  • relationsh_info：关联证明

    • scope：关联范围

    • keyword：关联关键字

  • type ✅：类型 wechat_oaccount:公众号 wechat_sapplet:小程序

  • username ✅：微信号

  • aliasname ✅：微信号别名

  • nickname：公众号/小程序名称

  • register_body ✅：注册主体

  • signature ✅：简介

  • appid ✅：AppID

  • apis：后台api接口

  • head_img ✅：公众号图标base64

  • tags：标签

  • is_offline ✅：服务状态 1:已离线 0：正常

  • change_state ✅：变动情况 1:变动 0：不变

  • status：处理状态 0:待确认 1:确认归属 2:忽略 3:仿冒资产 4:关停下架

  • register_time ✅：注册时间

  • insert_time ✅：云端收录时间

  • update_time ✅：本地更新时间

  • create_time ✅：本地创建时间

  • uptime ✅：云端更新时间

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

Note

✅ 表示该字段可排序
