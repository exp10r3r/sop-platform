结果列表

用于获取网盘监控数据

Request

请求地址

GET /api/v1/pan

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

keywords

关键字

模糊

file_type

文件类型

精确

name

文件名

模糊

url

地址

模糊

password

分享密码

模糊

path

目录

模糊

share_name

分享用户

模糊

pan_check

链接状态

精确

share_time

原始发布时间

范围

例如：2020-04-19/2020-09-19

云端收录时间

范围

范围

范围

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/pan?attach=count&id=1&name=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • keywords：关键字

  • relationsh_info：关联证明

    • scope：关联范围

    • keyword：关联关键字

  • file_type ✅：文件类型 （dir为文件夹）

  • name ✅：文件名

  • url ✅：地址

  • password ✅：分享密码

  • path ✅：目录

  • share_name ✅：分享用户

  • file_size：文件大小

  • pan_check ✅：链接状态 1:链接有效 0:链接失效

  • dir_struct：目录结构（仅dir类型的有值）

  • status: 处理状态 1:待确认 2:正在处理 3:已确认 4:忽略 5:已处置

  • type: 泄露信息分类 1: 敏感文档 2: 代码与配置

  • remarks: 备注

  • asource ✅：来源

  • share_time ✅：原始发布时间

  • createtime ✅：云端收录时间

  • local_uptime ✅：本地更新时间

  • local_create_time ✅：本地创建时间

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

Note

✅ 表示该字段可排序
