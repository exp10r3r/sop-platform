漏洞情报

用于获取漏洞情报数据

Request

请求地址

GET /api/v1/vulinfo

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

name

情报名称

模糊

flushtime

发布时间

范围

例如：2020-7-20/2020-8-20

poc_id

PoCID

精确

level

情报等级

精确多选

例如：严重,中危

source

情报来源

模糊

assetscount

受影响资产数

范围

如：100-3000

background

影响范围

模糊

is_read

已读状态

精确

1:已读 0：未读

fix_suggest

修复建议

模糊

reference

参考链接

模糊

influence

影响范围

模糊

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/vulinfo?attach=count&id=1&name=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • name ✅：情报名称

  • level ✅：情报等级

  • poc_id ✅：PoC ID

  • poc_title：PoC标题

  • flushtime ✅：刷新时间

  • source ✅：情报来源

  • assetscount ✅：受影响资产数

  • background ✅：相关背景

  • is_read：是否已读 1:是 0：否

  • fix_suggest ✅：修复建议

  • reference ✅：参考链接

  • influence ✅：影响范围

  • detail ✅：情报详情

Note

✅ 表示该字段可排序
