适配器IP数据

用于获取适配器IP数据

Request

请求地址

GET /api/v1/hosts_raw

字段

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/hosts_raw?attach=count&id=1&ip=1.1.1.1&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id：在数据库中的id

  • ip：IP地址

  • strmac：MAC地址

  • os：操作系统

  • hostname：主机名

  • custom_fields：自定义字段数据键值对

  • create_time：入库时间

  • valid_time：数据最近有效时间

  • collector_type：采集器类型

  • collector_id：采集器ID

  • raw_data：原始数据
