其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/webapp?attach=count&id=1&ip=1.1.1.1&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • ip ✅：IP地址

  • port ✅：端口

  • title ✅：页面标题

  • url ✅：URL地址

  • iocn_base64：网站icon（base64）

  • uptime ✅：更新时间

  • createtime ✅：创建时间

  • service ✅：服务类型

  • product ✅：应用名称

  • version ✅：版本信息

  • isp：运营商

  • address：地理位置

  • login_msg：登陆凭证

  • site_url：应用入口

  • level：应用等级

  • is_login ✅：是否登录入口 1:是 0：否

  • captcha ✅：是否有验证码 1:是 0：否

  • https ✅：是否Https服务 1:是 0：否

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

  • webfp ✅：Web指纹

  • remarks ✅：备注

  • ssl ✅：证书信息

  • status_code ✅：返回码

  • change_state ✅：资产变动状态 0：不变 1：新增 2：变化 3：减少

  • has_cap ✅：是否有截图 1:是 0：否

  • source：来源

Note

✅ 表示该字段可排序
