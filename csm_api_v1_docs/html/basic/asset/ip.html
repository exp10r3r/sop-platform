custom_fields
自定义字段搜索


















这是一个特殊的搜索，用法为：
custom_fields__{自定义字段名称}=值
例如：
custom_fields__文本字段=测试文本
根据自定义字段的类型，传值有不同的要求
1.单行文本框、多行文本框，值为字符串
例如：
custom_fields__文本框1=文本
2.下拉单选、下拉多选框，值为半角逗号分隔的字符串
例如：
custom_fields__多选=a,b,c
3.数值类型，值为半角逗号分隔的两个数字，表示搜索范围
例如：
custom_fields__数值1=10,31
4.日期类型，值为半角逗号分隔的两个日期字符串，表示搜索范围
根据时间精度有两种搜索，例如：
custom_fields__时间长=2025-05-21 14:58:07,2025-05-29 14:58:09
custom_fields__时间短=2025-05-01,2025-05-30

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/ip?attach=count&id=1&ip=1.1.1.1&ordering=-id

数据字段详解：

  • id ✅：在数据库中的id

  • ip ✅：IP地址

  • port：端口

  • service：服务

    • product：应用名称

    • version：版本信息

    • port：端口

    • service：服务类型

  • os ✅：操作系统

  • os_version ✅：操作系统版本

  • attribute：资产属性

  • secstate：安全属性

  • change_state ✅：资产变动状态 0：不变 1：新增 2：变化 3：减少

  • register：登记状态 0：未登记 1：已登记

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

  • uptime ✅：更新时间

  • createtime ✅：创建时间

  • taskids ✅：任务id

  • strmac ✅：mac地址

  • asource ✅：资产来源

  • location：地理位置

  • address ✅：机房地址

  • isp ✅：运营商

  • computer_room ✅：机房

  • cabinet ✅：机柜

  • equipment_number ✅：设备型号

  • bandwidth ✅：宽带

  • remarks ✅：备注

  • intranet_tag ✅：内网或外网 1：内网 0：外网

  • zone_name ✅：流量探针标签

  • ports_row ✅：端口号

  • services_row ✅：协议

  • strdevtype ✅：资产类别

  • strdevtype2 ✅：资产二级分类

  • macvendor ✅：设备厂商

  • custom_fields ✅：自定义字段数据键值对

Note

✅ 表示该字段可排序
