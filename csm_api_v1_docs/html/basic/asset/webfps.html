分类资产库

用于获取分类资产库数据

Request

请求地址

GET /api/v1/webfps

字段

说明

模糊

精确

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/webfps?attach=count&id=1&ip=1.1.1.1&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • target ✅：资产

  • port ✅：关联端口

  • cat ✅：二级分类

  • catid ✅：二级分类id

  • type ：一级分类

  • type_id ：一级分类id

  • app_name ✅：指纹名称

  • app_version ✅：附加信息

  • remarks ✅：备注

  • uptime ✅：更新时间

  • createtime ✅：更新时间

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

  • taskids ✅：任务id

Note

✅ 表示该字段可排序
