custom_fields
自定义字段搜索


















这是一个特殊的搜索，用法为：
custom_fields__{自定义字段名称}=值
例如：
custom_fields__文本字段=测试文本
根据自定义字段的类型，传值有不同的要求
1.单行文本框、多行文本框，值为字符串
例如：
custom_fields__文本框1=文本
2.下拉单选、下拉多选框，值为半角逗号分隔的字符串
例如：
custom_fields__多选=a,b,c
3.数值类型，值为半角逗号分隔的两个数字，表示搜索范围
例如：
custom_fields__数值1=10,31
4.日期类型，值为半角逗号分隔的两个日期字符串，表示搜索范围
根据时间精度有两种搜索，例如：
custom_fields__时间长=2025-05-21 14:58:07,2025-05-29 14:58:09
custom_fields__时间短=2025-05-01,2025-05-30

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/domain?attach=count&id=1&ip=1.1.1.1&ordering=-id

数据字段详解：

  • id ✅：在数据库中的id

  • name：域名

  • ipv4：A记录[ipv4]

  • ipv6：AAAA记录[ipv6]

  • cname：CNAME记录[别名]

  • analysis：解析状态 1:可解析 0：不可解析

  • cdn：是否CDN 1:是 0：否

  • register：登记状态 0：未登记 1：已登记

  • secstate：安全属性

  • domain：主域名

  • createtime ✅：创建时间

  • change_state ✅：资产变动状态 0：不变 1：新增 2：变化 3：减少

  • port：端口

  • uptime：更新时间

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

  • taskids ✅：任务id

  • domain_info：域名注册与备案信息

    • brother_info：主办单位关联域名

      • domain：关联域名

      • icp：备案号

      • verifytime：认证时间

    • beian_info：备案信息

      • domain：域名

      • icp_companytype：主办单位性质

      • icp_verifytime：审核通过日期

      • icp_companyname：主办单位名称

      • icp_license：ICP备案号

      • netsec_verifytime：审核通过日期

      • netsec_companyname：主办单位名称

      • netsec_companytype：主办单位性质

      • netsec_address：备案地址

      • netsec_license：许可证号

    • whois_info：所有者信息

      • domain：域名

      • dnsserver：DNS服务器

      • domainstatus：域名状态

      • contactperson：联系人

      • phone：所有者联系电话

      • registrar：注册商

      • expirationdate：到期时间

      • creationdate：注册时间

      • email：所有者联系邮箱

    • icp：ICP备案号

    • br_domains：关联域名

    • company_name：主办单位名称

  • address ✅：机房地址

  • isp ✅：运营商

  • computer_room ✅：机房

  • cabinet ✅：机柜

  • equipment_number ✅：设备编号

  • bandwidth ✅：宽带

  • remarks ✅：备注

  • custom_fields ✅：自定义字段数据键值对

Note

✅ 表示该字段可排序
