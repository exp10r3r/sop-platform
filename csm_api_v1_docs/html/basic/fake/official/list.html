疑似社交媒体列表

用于获取疑似社交媒体数据列表

Request

请求地址

GET /api/v1/fake/official

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

discover_time

发现时间

范围

例如：2020-7-20/2020-8-20

name

仿冒媒体名称

模糊

account_id

仿冒媒体编号

模糊

befaked_name

被仿冒媒体名称

模糊

institution_short

被仿冒的机构名称

模糊

institution_code

被仿冒的机构代码

模糊

target_industry

被仿冒的行业代码

模糊

provider

服务商

模糊

source

情报来源

模糊
status
处置状态
精确
可选值:
2：正在处理
3：已确认
4：忽略
5：已处理

handle_time

处置时间

范围

例如：2020-7-20/2020-8-20

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/fake/official?attach=count&id=310&account_id=gh_123445&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • discover_time ✅：发现时间

  • name ✅：仿冒媒体名称

  • account_id ✅：仿冒媒体编号

  • befaked_name ✅：被仿冒媒体名称

  • institution_short ✅：被仿冒的机构名称

  • institution_code ✅：被仿冒的机构代码

  • target_industry ✅：被仿冒的行业代码

  • provider ✅：服务商

  • source ✅：情报来源

  • status ：处置状态

  • handle_time ：处置时间

Note

✅ 表示该字段可排序
