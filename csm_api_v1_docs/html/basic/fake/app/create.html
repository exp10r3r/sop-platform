录入疑似APP

用于录入疑似APP数据

Request

请求地址

POST /api/v1/fake/app

请求参数

字段

字段名称

是否必填

说明

示例

discover_time

发现时间

否

2024-10-18 10:03:34

name

仿冒APP应用名

是

download_url

仿冒APP下载地址

是

befaked_md5

被仿冒APP MD5

否

links

后台链接

否

befaked_name

被仿冒APP应用名

是

befaked_package

被仿冒APP应用包名

否

befaked_version

被仿冒APP版本号

否

institution_short

被仿冒的机构名称

是

institution_code

被仿冒的机构代码

否

target_industry

被仿冒的行业代码

否

provider

服务商

否

company

仿冒APP公司名

否

country

公司归属国家编码

否

province

公司归属省份编码

否

city

公司归属城市编码

否

register_addr

公司注册地址

否

emails

邮箱地址

否

work_addr

公司办公地址

否
