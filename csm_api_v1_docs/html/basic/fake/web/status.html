处置疑似网站

用于处置疑似网站

Request

请求地址

PUT /api/v1/fake/web/handle_status

请求参数

字段

字段名称

是否必填

说明

示例

id

ID

是

需要处置的id列表
status
处置状态
是
可选值:
2：正在处理
3：已确认
4：忽略
5：已处理

请求示例

import requests

url = "http://127.0.0.1:8000/api/v1/fake/web/handle_status"

payload = json.dumps({
    "id": [319],
    "status": 2
})
headers = {
    'Accept': 'application/json',
    'Content-type': 'application/json',
    'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
    'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
}

response = requests.request("PUT", url, headers=headers, data=payload)

print(response.text)

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

string/dict

返回结果信息

示例值

{
    "info": "操作成功",
    "status": true
