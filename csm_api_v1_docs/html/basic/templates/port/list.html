端口模板列表

用于获取端口模板数据

Request

请求地址

GET /api/v1/template/port

搜索参数

字段

字段名称

查询方式

说明

id

id

精确

user_id

创建用户id

精确多选

name

模板名称

模糊

value

端口值

模糊

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/template/port?attach=count&id=1&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：在数据库中的id

  • name ✅：模板名称

  • value ✅：端口值

  • user_id ✅：创建用户id

Note

✅ 表示该字段可排序
