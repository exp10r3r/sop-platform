删除应用组

用于删除应用组

Request

请求地址

DELETE /api/v1/group/app/{id}

请求参数

无

请求示例

import requests

url = "http://127.0.0.1:8000/api/v1/group/app/3750"

payload = ""
headers = {
    'Accept': 'application/json',
    'Content-type': 'application/json',
    'ACCESSKEY': 'ijE80piSATBYT8qVQcInSygUomWl6FiQFZ9LwhdZBv0eJ6QQFHQcHw',
    'SECRETKEY': 'P4KNH51u6KyewjCfX1JZ3uZ7bCV4tTME6JcbBvmrUQTZ7YxOltUjCIiNUrp24ijq8'
}

response = requests.request("DELETE", url, headers=headers, data=payload)

print(response.text)

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

string/dict

返回结果信息

示例值

{
    "info": "删除成功",
    "status": true
}

失败示例

{
    "info": {
        "detail": "Not found."
    },
    "status": false
}
