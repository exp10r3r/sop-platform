编辑网络组范围登记

用于编辑网络组范围登记

Request

请求地址

PUT /api/v1/group/net/scope/{id}

请求参数

字段

字段名称

是否必填

说明

示例

value

资产范围

是

priority

优先级

是

1-100
scope_type
范围类型
是
0:IP/域名
1:资产来源
2:关联任务



groupids

网络组id

否

remarks

备注

否

address

地址

否

computer_room

机房

否

isp

运营商

否

bandwidth

带宽

否

cabinet

机柜

否

equipment_number

设备编号

否

请求示例

import requests
import json

url = "http://127.0.0.1:38202/api/v1/group/net/scope/1728"

payload = json.dumps({
    "value": "11112313",
    "priority": 1,
    "scope_type": "1",
    "groupids": [
        7389
    ],
    "remarks": "备注",
    "address": "地址",
    "computer_room": "机房",
    "isp": "运营商",
    "bandwidth": "带宽",
    "cabinet": "机柜",
    "equipment_number": "设备编号"
})
headers = {
    'ACCESSKEY': 'B6xsfMw2SztH3YTv5bWLHynfciajICMgNWomlFOhn14xcssRQQk0Q',
    'SECRETKEY': 'FhfAkrtBNnjRHQdnF0H0JiDeHykb0tQb0JlLSFu9v92Tp31i3M22EaIMSVIKqi8lk',
    'Content-Type': 'application/json',
    'Cookie': 'sessionid=4dw4q32m1i9b98mmb7ymuynm0ol8jjfs'
}

response = requests.request("PUT", url, headers=headers, data=payload)

print(response.text)
