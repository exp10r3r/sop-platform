复扫子任务列表

用于获取任务列表

Request

请求地址

GET /api/v1/verify_history

搜索参数

字段

字段名称

查询方式

说明

id

ID

精确

verify_id

复扫任务ID

精确

verify_ip

复扫目标

模糊

port

复扫端口

精确

verify_info

复扫信息

模糊

message_id

消息ID

精确
verify_type
复扫类型
精确
port:端口复扫
scanc:版本型漏洞复扫
scan:PoC漏洞复扫

start_time

开始时间

范围

例如：2020-7-20/2020-8-20

end_time

结束时间

范围

例如：2020-7-20/2020-8-20

logs

日志

模糊
status
复扫状态
精确多选
可选值:
复扫成功：漏洞遗留
复扫成功：漏洞减少
复扫成功：端口遗留
复扫成功：端口变动
复扫成功：端口减少
复扫失败：超时
正在复扫中

assets_group_id

资产组id

精确多选

assets_group_user_id

资产组责任人id

精确多选

username

用户名

模糊

user_id

用户id

精确

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/verify_history?attach=count&id=1&name=test&ordering=-id

Response

响应参数

参数

类型

描述

status

boolean

是否成功

info

array

返回数据

count

integer

总数（当请求参数attach=count存在时）

数据字段详解：

  • id ✅：ID

  • verify_id ✅：复扫任务ID

  • verify_ip ✅：复扫目标

  • port ✅：复扫端口

  • verify_info ✅：复扫信息

  • message_id ✅：消息ID

  • verify_type ✅：复扫类型

  • start_time ✅：开始时间

  • end_time ✅：结束时间

  • assets_group：资产组及资产责任人

    • net：网络组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

    • app：应用组

      • id：网络组id

      • name：网络组名称

      • resposibler：责任人用户名

  • logs ：日志

  • status ：复扫状态

  • user_id ：用户id

  • username ：用户名

Note

✅ 表示该字段可排序
