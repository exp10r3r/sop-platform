任务配置详情列表

用于获取任务配置详情列表

请求地址

GET /api/v1/task_manage

其他参数

参数

参数名称

可选值

说明
attach
附加项
count
可选，传count时，进行统计数量, 并在接口中返回
例如:
?attach=count

请求示例

https://localhost:38201/api/v1/task_manage?attach=count&id=1&name=test&ordering=-id

数据字段详解：

  • id ✅：在数据库中的id

  • name ✅：任务名称

  • scan_type ✅：扫描方式 base：基础模式 domain：主域模式 pocscan：PoC插件巡检 thirdscan：第三方扫描

  • task_type ✅：任务类型 senior：高级自定义 assets：资产盘点 version：版本型漏洞扫描 poc：PoC扫描 pocscan：PoC漏洞巡检`

  • value_type ✅：目标范围 customize：自定义 exist_ip：资产库所有IP和域名 business：资产组

  • value：目标值

  • cycle ✅：扫描频率设置 0:单次执行 1:周期执行 2:计划执行

  • cycle_interval_type ✅：扫描频率类型 cycle值为1时: day：天 hour：小时 cycle值为2时: day:每天 week:每周 month:每月

  • cycle_interval ✅：扫描频率

  • cycle_scantime ✅：「禁止扫描时间」模板id

  • portdeep ✅：端口发现方式 1：急速模式 2：标准模式

  • port_type ✅：端口类型 all：全端口 template：端口模板 general：常规端口 customize：自定义端口 self-adaption：自适应端口

  • portargv ✅：端口值

  • status ✅：任务状态 基础模式: 0: 未开始 -1: 暂停 1: 端口服务探测 3: os识别 5: 插件扫描 6: 完成 7: 任务终止 主域模式: 0: 未开始 -1: 暂停 10: 子域名收集 11: 端口探测 12: 数据分析 13: 初步端口探测 15: 站点指纹识别 3: os识别 5: os识别完成 6: 完成 7: 任务终止

  • zone_name ✅：扫描区域标识

  • start_time ✅：开始时间（实际执行）

  • end_time ✅：结束时间

  • create_time ✅：创建时间

  • task_start_time ✅：开始扫描时间（用户设置值）

  • scanids ✅：「扫描插件模板」id

  • cpescan ✅：是否进行版本型扫描 1：是 0：否

  • osscan_mode ✅：是否进行操作系统识别 1：是 0：否

  • doit ✅：启动状态 1：启动中 0：暂停中

  • user_id: 用户id

  • plugin_type ：插件模板值类型 type：按插件类型指定PoC插件 level：按漏洞等级指定PoC插件

  • plugin_type ：插件模板值

  • plugin_type ：额外指定插件id

  • if_confirm ✅：是否审核通过 1：是 0：否

  • confirm_msg ：审核信息

Note

✅ 表示该字段可排序
