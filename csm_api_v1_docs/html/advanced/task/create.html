创建任务

用于创建扫描任务

Request

请求地址

POST /api/v1/task_manage

请求参数

字段

字段名称

是否必填

说明

示例

name

任务名称

是
zone_name
扫描区域标识
否
scan_type 为 base、domain、pocscan时必填
可选值从 「扫描区域列表」 中查询


scan_type
扫描模式
是
base：基础模式
domain：主域模式
pocscan：PoC巡检
thirdscan：第三方扫描





port_type
端口类型
否
scan_type 为 base、domain时必填
all：全端口
template：端口模板
general：常规端口
customize：自定义端口
self-adaption：自适应端口






portargv
端口取值范围
否
scan_type 为 base、domain时必填
根据端口类型传值


value_type
扫描目标范围
是
customize：自定义
exist_ip：资产库所有IP和域名
business：资产组



value
扫描目标取值
是
根据扫描目标范围传值
当 value_type=customize 时，多个ip使用n分隔


scanids

扫描插件模板id

否

cycle

扫描频率

是

0:单次扫描 1:周期执行 2:计划执行

cycle_interval

周期扫描间隔

是
cycle_interval_type
周期扫描间隔时间单位类型
否
可选
cycle为1时:
hour：小时
day：天
cycle为2时:
day:每天
week:每周
month:每月

不传时默认值为 day










cycle_start
扫描开始阶段
否
scan_type为base时,可选值为:
0 端口扫描
2 OS识别
4 插件扫描

scan_type为domain时,可选值为:
0 子域名收集
12 端口探测
14 站点指纹识别
2 OS识别
4 插件扫描

其他模式无需传值













portdeep
扫描方式
否
scan_type 为 base、domain时必填
1：极速模式
2：标准模式



cycle_scantime

禁止扫描时间模板id

否
cpescan
是否进行版本型扫描
否
scan_type 为 base、domain时必填
1：是
0：否



osscan_mode
是否进行操作系统识别
否
不传时默认值为1
1：是
0：否



task_start_time

任务开始时间

否

例如：2024-05-22 17:23:13
plugin_type
插件模板值类型
否
type：按插件类型指定PoC插件
level：按漏洞等级指定PoC插件


plugin_value
插件模板值


否
当plugin_type为type时，可选值有：
CMS-WordPress、None、缓冲区溢出、权限绕过、CMS-other、默认口令、目录遍历、XML实体注入、
弱口令、文件包含、未授权访问、用户枚举、github、URL重定向、目录浏览、CMS-Discuz、
任意文件读取、远程代码执行、用友、跨站脚本攻击(XSS)、SSRF服务端请求伪造、海康、
后门/backdoor、DOS、站点指纹、敏感信息泄露、SQL注入、文件上传、设计缺陷、2021HW漏洞、CMS-DedeCms、平行权限、CMS-PHPCMS

当plugin_type为level时，可选值有：
严重、高危、中危、低危








plugin_id

插件id

否

用于额外指定PoC插件id
taskcfg
第三方扫描任务-扫描器配置
否
scan_type 为 third_scan时必填
通常为可配置的自定义规则，在「系统设置」「平台联动」「第三方引擎配置」中进行配置
配置完成后，此字段的需要提交的数据的校验规则可以使用接口 「扫描器配置字段详情」 获取

字段格式为字典格式，包含的内容有扫描器类型、扫描器列表

type 为字符串格式表示要调用扫描的扫描器类型
config 为数组格式，是具体到每一个扫描器的配置信息
config 的元素是字典格式:
字典中collector_id 是必填项，指定了调度的扫描器ID
字典的其他键值对，由「扫描器配置字段详情」决定，如例子中的 policy_id 即是相应的键

{
“type”: “tenablesc”,
“config”: [
{
“collector_id”: 144,
“policy_id”: “CVM_FULL_PLUGI111NS”
}
]
}

Note

plugin_id、plugin_type、plugin_value 仅在scanids字段为空时生效，用于选择插件并生成一个新的模板（该模板仅当前任务可用）

    "type": "tenablesc",
    "config": [
    {
        "collector_id": 144,
        "policy1_id": "CVM_FULL_PLUGI111NS"

    ]

})

'Content-Type': 'application/json',
