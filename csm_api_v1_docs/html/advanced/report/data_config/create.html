创建模板

用于创建新的导出数据模板

Request

请求地址

POST /api/v1/report/data/config

请求参数

字段

字段名称

是否必填

说明

示例

name

导出任务名称

是

type

Excel版本

是

xlsx或xls

task_ids

关联任务ID

否

数组格式

group_ids

关联资产组ID

否

数组格式
condition
需要导出的数据表名
是
数组格式

ip: IP资产
task: 扫描任务
assets_group: 资产组
domain: 域名资产
port: 端口服务
poc: PoC漏洞
version: 版本型漏洞
riskcollector: 第三方漏洞
riskport: 高危端口
unconventional: 非常规端口
riskport_rule: 高危端口-监控规则
conventional_rule: 常规端口-监控规则
riskport_white: 高危端口-白名单规则
webfps: 分类资产库
pan: 网盘监控
wechat: 公众号小程序
doc: 文档监控
git: 开源社区监控
darkweb: 暗网监控
wechat-keyword: 暗网监控-监控关键字
doc-keyword: 文档监控-监控关键字
pan-keyword: 网盘监控-监控关键字
git-keyword: 开源社区监控-监控关键字
darkweb-keyword: 暗网监控-监控关键字
net_scope: 网络组范围登记
app_scope: 应用组范围登记
application: APP资产监控
application-keyword: APP资产监控-关键字
url: URL列表
shadow: 影子资产
































fields
指定的自定义字段
否
字典格式，键为数据表名，值为指定的自定义字段
为空时默认导出所有字段
具体可选的值可以在 「自定义导出字段详情」 中查询



cycle

是否周期任务

是

0:否 1:是

value

执行周期间隔

是

单位为天，当cycle为1时生效

cycle_run_time

周期任务在执行当日的具体执行时间

否

当cycle为1时必填，格式：09:00:00

task_start_time

开始时间

是

格式：2023-03-21 14:27:45

system_userids

邮件发送对象用户id

否

数组格式

custom_email

邮件发送对象-系统外用户邮箱

否

字符串格式，多个邮箱使用 \n 分隔
file_type
文档拆分
否
user: 报告按照系统用户进行拆分（严格按照定义角色权限生成）
user_by_group: 报告按照系统用户进行拆分（不按照定义角色权限生成，而是按照资产登记的结果来生成）
group：按照资产组进行拆分
空值: 不进行拆分




请求示例

import requests
import json

url = "http://127.0.0.1:38202/api/v1/report/data/config"

payload = json.dumps({
"name": "tast-api-report-data112",
"type": "xlsx",
"task_ids": [
    112
],
"group_ids": [
    7391
],
"condition": [
    "task",
    "ip",
    "poc"
],
"fields": {},
"cycle": 1,
"value": 7,
"cycle_run_time": "09:00:00",
"task_start_time": "2024-03-21 09:11:43",
"system_userids": [
    1
],
"custom_email": "test11@test123456.com\ntest112@test123456.com",
"file_type": ""
})
headers = {
'Content-Type': 'application/json',
'Cookie': 'sessionid=550q0nyl2gijkeqxhu2kibep5wgdxrin'
}

response = requests.request("POST", url, headers=headers, data=payload)

print(response.text)
